# k_timer

キッチンタイマー。横長モニタやタブレットでは左にアナログ時計、右にタイマーを表示する。`index.html` と `audio/` だけで動く。

## 機能

- プリセット 3 つ(既定 3 / 5 / 12 分)。± ボタン `-10 -1 -0.5 00 +0.5 +1 +10`(分。0.5 = 30 秒)
- スタート / ストップ(一時停止) / リセット(開始値に戻す)
- 動作中も ± で終了時刻を動かせる。`00` は停止中は残りの秒を切り捨て、動作中は終了時刻の秒を 00 に切り下げ
- 動作中は「終了 HH:MM」を表示
- 0 になると終了音がループし、画面が点滅、超過を `-m:ss` で表示。画面のどこかをタップ(またはキー入力)するまで鳴り続ける
- 終了音 3 種(`audio/sound2-*.wav`)、音量、点滅 ON/OFF、秒針 ON/OFF
- 幅 700px 未満ではアナログ時計を隠しタイマーだけ表示
- 右上のアイコンで ダーク/ライト、拡大/縮小、フルスクリーン、日英。設定は歯車

## 設定項目

| キー | 型/範囲 | 既定 | 説明 |
|---|---|---|---|
| `preset1`〜`preset3` | 整数 1〜180 | 3 / 5 / 12 | プリセットの分 |
| `sound` | `sound2-1` / `sound2-2` / `sound2-3` | `sound2-1` | 終了音 |
| `volume` | 整数 0〜100 | 80 | 音量 |
| `flash` | 真偽 | true | 終了時に画面を点滅 |
| `seconds` | 真偽 | true | 秒針を表示 |
| `lang` / `theme` / `zoom` | 共通 | 共通 | 言語 / テーマ / 拡大率(共通設定) |

## URL パラメータ

| パラメータ | 例 | 説明 |
|---|---|---|
| `preset1`〜`preset3` | `preset1=4` | プリセットの分(1〜180) |
| `sound` | `sound=sound2-2` | 終了音 `sound2-1` / `sound2-2` / `sound2-3` |
| `volume` | `volume=50` | 音量 0〜100 |
| `flash` | `flash=0` | 終了時の画面点滅(`1`/`0`、`true`/`false` も可) |
| `seconds` | `seconds=0` | 秒針(`1`/`0`、`true`/`false` も可) |
| `lang` / `theme` / `zoom` | `lang=en` | 共通 |
| `save` | `save=1` | URL の設定を localStorage に保存 |

タイマーの状態は保存しない。再読込すると `preset1` の停止状態に戻る。

## データの保存形式

localStorage キー `simplePages.k_timer`:

```json
{ "version": 1, "settings": { "lang": "ja", "theme": "auto", "zoom": 100,
  "preset1": 3, "preset2": 5, "preset3": 12, "sound": "sound2-1", "volume": 80, "flash": true, "seconds": true } }
```

## 音声

`audio/sound2-1.wav`(ロングトーン、mixkit.co `mixkit-happy-bells-notification-937`、Mixkit License)、`sound2-2.wav`(ダブルビープ)、`sound2-3.wav`(下降トーン)。読み込めないときはステータスが赤になり、Web Audio の 880 Hz ビープで代替する。

iOS Safari は `<audio>` の音量変更を受け付けないため、音量設定は終了音には効かず、ビープ代替にのみ効く。

ブラウザの自動再生制限のため、音はスタートを押した(ユーザー操作があった)あとにだけ鳴る。

```bash
node --test k_timer/test/*.test.mjs
```

## 手動確認

- 5 分 → スタートで `4:59` から減り「終了 HH:MM」が出る。ストップ/スタートで一時停止と再開、リセットで `5:00`
- 動作中 `+1` で終了が 1 分遅れる。`00` で終了時刻の秒が 00 になる
- 0 到達で音がループ・画面点滅・`-0:03` と超過が進む。画面のどこかをタップすると止まり開始値に戻る。ボタンを叩いて止めたときにそのボタンが作動しない
- 設定で音を変えて試聴、音量が反映される。点滅 OFF、秒針 OFF が効く
- 幅 700px 未満で時計が消える。`zoom=150` でもボタンが収まる
- `audio/` を一時的にリネームするとステータスが赤、ビープで鳴る
