# midsleep

睡眠の中央時刻(就寝と起床のまん中の時刻)を毎日そろえるための、スマートフォン向けの記録・目安ツール。寝る直前と起きた直後にボタンを 1 回押すだけで記録し、「今寝ると何時に起きるとよいか」「何時に起きるには何時に寝ればよいか」を目標の中央時刻から示します。`index.html` 1 ファイルで動き、データはブラウザの localStorage にだけ保存されます(サーバーへは何も送りません)。

## 機能

下部のタブは 3 つ。

- 今日: 夜タイルと朝タイルの 2 枚。起きているときは、夜タイルが「今寝ると、起きるのは HH:MM(睡眠 X ・ 中央 HH:MM)」と「今から寝る」ボタン、朝タイルが「HH:MM に起きるなら、寝るのは HH:MM(睡眠 X ・ あと Y)」と ‹ › の 15 分刻みの調整。寝る時刻を過ぎていれば「もう過ぎています ・ 今寝ると中央は …」。記録が 2 件未満なら `--:--`。就寝中は、夜タイルが「HH:MM から寝ています」と経過時間・「いま起きると 中央 …」と、小さなリンク「就寝時刻を直す」「取り消す」、朝タイルが「目標どおりなら HH:MM」(睡眠が 12 時間を超える場合は `--:--`)と「今起きた」ボタン。睡眠の長短の注意や目標・ばらつき、直近の記録の要約は今日タブには出さない(履歴タブの統計行にある)
- 履歴: 14 日 / 30 日のグラフ(棒は就寝から起床、赤点は中央時刻、青点線は目標)、統計行(目標・ばらつき・平均睡眠)、記録の一覧。一覧の行をタップすると編集・削除、「記録を追加」で押し忘れた記録を足せる
- 設定: 表示 / 計算 / データ / About。言語・テーマ・拡大率は右上のツールバーで切り替える(このページにはフルスクリーンボタンはない。ツールバーはダーク/ライト、拡大、縮小、日英、設定)

押し忘れや、布団に入ってから寝入るまでのずれは、あとから履歴で直します(ボタンを押した時刻はそのまま記録する)。

## 計算の定義

- 中央時刻: 就寝と起床のまん中の時刻(時刻のみ、日付は捨てる)
- 目標: 直近 `avgDays` 日(起床日が今日から `avgDays - 1` 日前以降)の記録の中央時刻の円周平均。23:00 と 1:00 の平均は 0:00。有効な記録が 2 晩分たまるまで出ない
- ばらつき: 同じ窓の中央時刻の、目標からの円周上の差の母集団標準偏差(分)。統計行のばらつきと平均睡眠は `chartDays` の窓で計算し、目標だけは `avgDays` の窓(今日タブの目安の計算と同じ値)
- 仮眠: 長さ 3 時間未満の記録。履歴の一覧とグラフには出すが、目標・ばらつきの計算には使わない。グラフの軸(既定 21:00〜9:00)も仮眠では広げず、軸の外に完全に収まる仮眠は描かない
- 就寝中の記録は目標・ばらつき・履歴(グラフ・統計・一覧)に入れない
- 今寝ると: 中央時刻が今より厳密に後に来る最初の時刻 M をとり、起床 = 今 + 2 × (M − 今)
- 起きたい時刻: 起床時刻より厳密に前に来る最後の中央時刻 M をとり、就寝 = 起床 − 2 × (起床 − M)。起床は `wakeTarget` が次に来る日時。就寝が今より前なら「もう過ぎています」と薄く表示する。‹ › で 15 分刻みに動かせる
- 押し忘れ: 就寝中の記録が `staleHours` 時間以上になると夜タイルに押し忘れのカードを出し、起床時刻を入れて記録するか取り消せる。就寝中の記録は常に 1 件まで

## 設定項目

| セクション | キー | 型 | 既定 | 説明 |
|---|---|---|---|---|
| 共通 | `lang` | `'ja' \| 'en'` | 言語検出 | ツールバーで切り替え |
| 共通 | `theme` | `'auto' \| 'light' \| 'dark'` | `auto`(OS) | ツールバーで切り替え |
| 共通 | `zoom` | 50〜200 | 100 | ツールバーで切り替え |
| 表示 | `chartDays` | 14 \| 30 | 14 | 履歴グラフと統計の窓(日)。履歴タブのセグメントと連動 |
| 表示 | `wakeTarget` | `HH:MM` | `06:00` | 起きたい時刻。今日タブの ‹ › と連動。形式が不正なら `06:00` に戻す |
| 計算 | `avgDays` | 3〜30 | 7 | 目標の中央時刻を求める窓(日) |
| 計算 | `minSleepMin` | 180〜720 | 360 | UI には表示しない。データ互換と Logic.adviceFlags の判定のためだけに残している |
| 計算 | `staleHours` | 10〜36 | 18 | 就寝中がこの時間以上たったら押し忘れとみなす |

整数の設定は範囲外の値を範囲の端に丸める(既定には戻さない)。

## URL パラメータ

設定キーと同名のパラメータで指定できる(`?theme=dark&zoom=120&lang=en`)。共通で使えるのは `theme` `zoom` `lang`。

- `tab`: 開くタブ。`today`(既定) / `history` / `settings`(保存しない)
- `save=1`: 指定した設定値を localStorage に保存する(付けなければ保存しない)

優先順位は URL クエリ > localStorage > 既定値。

## データ形式

localStorage に次の 2 つのキーで保存します。

- `simplePages.midsleep` — `{ version, settings }`。上の設定項目。
- `simplePages.midsleep.data` — `{ version, records }`。睡眠の記録。

```json
{
  "version": 1,
  "records": [
    { "id": "r_1760900000000", "bedAt": "2026-10-19T23:12", "wakeAt": "2026-10-20T06:31", "createdAt": "2026-10-19T23:12:04+09:00" },
    { "id": "r_1760990000000", "bedAt": "2026-10-20T23:05", "wakeAt": null, "createdAt": "2026-10-20T23:05:10+09:00" }
  ]
}
```

- `bedAt` / `wakeAt` はローカル時刻の `YYYY-MM-DDTHH:MM`(タイムゾーンなし)。`wakeAt` が `null` なら就寝中
- 読み込み時と保存時に正規化する: 形式違反の記録は捨て(捨てた数を知らせる)、就寝中の記録は最新の 1 件だけ残し、`bedAt` 昇順に並べる

書き出しは設定とデータを 1 つにまとめた JSON で、ファイル名は `midsleep-YYYYMMDD.json`。データタブのテキスト欄にも同じ JSON が表示される。

```json
{
  "version": 1,
  "settings": { "lang": "ja", "avgDays": 7 },
  "data": { "version": 1, "records": [] }
}
```

読み込みは `settings`、`data`、または両方を受け付け、含まれている側を**置き換える**(統合はしない)。実行前に確認ダイアログを出す。含まれていない側は変更しない。「すべて消去」は 2 つのキーを両方消して既定値に戻す。

## ホーム画面への追加(PWA)

`manifest.webmanifest` と `icons/` を同梱しているので、Android Chrome の「インストール」や iOS Safari の「ホーム画面に追加」で全画面のアプリとして開ける(`display: standalone`)。Service Worker は置いていない(インストール専用)ので、起動には通信が要り、更新は次回起動時にサーバーから読み直す。iOS ではホーム画面から開いたアプリとブラウザで localStorage が別になるため、データはエクスポート/インポートで移す。アイコンは `icons/icon-192.png` / `icon-512.png` と `icons/apple-touch-icon.png`(180px)。
