
# simplePages

index.html だけで動くシンプルなページの集まりです。各ディレクトリの `index.html` をブラウザで開くか、静的ホスティングに置いて使います。

公開ページ: <https://xpenguin.biz/simplePages/>(ルートの `index.html` が各ページへの入口です)

ページは主な使われ方で 3 つに分けています。

## キオスク向け

横長の画面に常時表示して、ほとんど触らずに眺めるページ。フルスクリーンにして設置します。

| ページ | 説明 |
|---|---|
| `weather/` | 1 地点の天気予報を横長 1 画面に常時表示 |
| `calendar/` | Google カレンダーの予定を日・週・月で常時表示 |
| `k_timer/` | キッチンタイマー(アナログ時計とプリセット、± 調整、終了音) |

## PC 作業向け

PC のブラウザで開いたまま、作業の脇で操作するページ。

| ページ | 説明 |
|---|---|
| `l_timer/` | 講義用タイマー(講義と休憩の繰り返し、予鈴・終了音、演習タイマー、メモエディタ) |

## スマートフォン向け

縦持ちのスマートフォンで指で操作するページ。ホーム画面に追加して使えます。

| ページ | 説明 |
|---|---|
| `time4u/` | 面会日程の候補提示。週ごとの面会可能帯から空き枠を選んで文面を作り、回答まで仮押さえ |
| `midsleep/` | 睡眠中央時刻の記録と目安。就寝・起床をワンタップで記録し、起床・就寝の時刻を提案、履歴グラフで振り返り |

## 共通

どのページも右上のアイコンでダーク/ライト、拡大/縮小、日英、設定を切り替えられます(キオスク向けと PC 作業向けにはフルスクリーンもあります)。設定とデータはブラウザの localStorage にだけ保存され、設定のデータタブで JSON として書き出し・読み込みできます。

`_template/` は新しいページのひな形(キオスク向け・PC 作業向け)です。規約と作り方は `docs/conventions.md`、要約は `CLAUDE.md` を参照してください。ライセンスは MIT(`LICENSE`)。
