# simplePages

index.html だけで動くシンプルなページの集まりです。各ディレクトリの `index.html` をブラウザで開くか、静的ホスティングに置いて使います。

公開ページ: <https://xpenguin.biz/simplePages/>(ルートの `index.html` が各ページへの入口です)

| ページ | 説明 |
|---|---|
| `_template/` | 新しいページのひな形 |
| `weather/` | 1 地点の天気予報を常時表示 |
| `calendar/` | Google カレンダーの予定を日・週・月で常時表示 |
| `k_timer/` | キッチンタイマー(アナログ時計付き) |
| `l_timer/` | 講義用タイマー(演習タイマーとメモエディタ付き) |

各ページは右上のアイコンでダーク/ライト、拡大/縮小、フルスクリーン、日英、設定を切り替えられます。ライセンスは MIT(`LICENSE`)。

共通規約と作り方は `CLAUDE.md` を参照してください。
