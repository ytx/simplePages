# Calendar Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `calendar/index.html`, a single-file always-on page that shows Google Calendar events (several calendars) in day / week / month views, fetched through a Google Apps Script (GAS) web app the user deploys from `calendar/gas/Code.gs`.

**Architecture:** The page is a copy of `_template/index.html` (toolbar, bottom status bar, fixed-size settings modal, `--zoom`). Pure date/layout/response logic lives in `Logic` and is unit-tested with Node; `App` fetches a cached window of events around the visible range, renders a time grid (day/week) or a 6×7 month grid, and handles swipe, nav buttons, popover and return-to-today. The GAS script is a thin JSON front for `CalendarApp`.

**Tech Stack:** Vanilla HTML/CSS/JS, `<dialog>`, Pointer Events, Intl, Node `node:test`; Google Apps Script (`CalendarApp`, `ContentService`).

**Spec:** `docs/superpowers/specs/2026-10-13-calendar-design.md` (plus the shared specs `2026-10-12-simplepages-conventions-design.md` and `2026-10-13-toolbar-and-settings-modal-design.md`).

## Global Constraints

- One page = `calendar/index.html` alone. No external `<link>`, `<script src>`, CDN, web fonts.
- Only two globals: `Logic` (pure, `<script id="app-logic">`) and `App` (`<script id="app-ui">`).
- Every externally supplied string (event title, location, description, calendar name, error text) is inserted with `textContent`/`createTextNode`; never `innerHTML`. `href` values only from constants.
- All size tokens multiply by `var(--zoom)` exactly once; nav buttons are at least `calc(48px * var(--zoom))` tall and wide.
- Settings stored at `simplePages.calendar` as `{ version: 1, settings }`; priority URL > localStorage > defaults; `?save=1` persists. `date=YYYY-MM-DD` is a URL-only anchor and is never saved.
- `DISPLAY_ONLY_KEYS` = theme, zoom, lang, view, weekStart, dayStart, dayEnd, returnToTodayMinutes.
- GAS URL accepted only if it matches `^https://script\.google\.com/macros/s/[A-Za-z0-9_-]+/exec$`.
- Fetches use the shared `fetchJson` (20 s timeout) with no custom headers (CORS simple request); stale responses are dropped with a generation counter; on failure the previous data stays and the status turns red with the last-OK time.
- Tests: `node --test calendar/test/*.test.mjs` (glob form). Test files set `process.env.TZ = 'Asia/Tokyo'` in `load-logic.mjs` so date math is deterministic. No network in tests.
- Commits end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. A timed event crossing midnight (23:30–00:30) must appear on both days, clipped at midnight, and never as an all-day bar. (Task 4 tests `segmentsByDay`.)
2. Three overlapping events must share the column width without covering each other; an event starting when another ends must reuse that column. (Task 4 tests `layoutColumns`.)
3. Events outside the displayed hours (05:00–07:00 with dayStart 6) must be drawn clipped, not dropped, and a 22:00–23:59 event must not overflow the grid. (Task 4 tests `clipToHours`.)
4. A GAS deployment with the wrong access setting returns an HTML authorization page; the user must see a message pointing at the deployment settings, not a raw JSON parse error. (Task 7 maps JSON parse failures to `invalid_response`; Task 3 tests `normalizeResponse` on non-objects.)
5. A pasted GAS URL with `/dev` or `http://` must be rejected visibly, and the previous valid URL must not be silently used. (Task 3 tests `validGasUrl`; Task 7 shows `invalid_url` in the connection tab.)

```js
  // ---- 日付 ----
  const DAY_MS = 86400000;
  const WEEKDAYS_JA = ['日', '月', '火', '水', '木', '金', '土'];

  function startOfDay(d) { return new Date(d.getFullYear(), d.getMonth(), d.getDate()); }
  function addDays(d, n) { const r = startOfDay(d); r.setDate(r.getDate() + n); return r; }
  function addMonths(d, n) { return new Date(d.getFullYear(), d.getMonth() + n, 1); }
  function ymd(d) {
    return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`;
  }
  function parseYmd(s) {
    const m = /^(\d{4})-(\d{2})-(\d{2})$/.exec(String(s || ''));
    if (!m) return null;
    const y = Number(m[1]), mo = Number(m[2]) - 1, da = Number(m[3]);
    const d = new Date(y, mo, da);
    return d.getFullYear() === y && d.getMonth() === mo && d.getDate() === da ? d : null;
  }
  function startOfWeek(d, weekStart) {
    const s = startOfDay(d);
    return addDays(s, -((s.getDay() - weekStart + 7) % 7));
  }
  function monthGridDays(anchor, weekStart) {
    const first = new Date(anchor.getFullYear(), anchor.getMonth(), 1);
    const start = startOfWeek(first, weekStart);
    const days = [];
    for (let i = 0; i < 42; i++) {
      const date = addDays(start, i);
      days.push({ date, inMonth: date.getMonth() === first.getMonth() });
    }
    return days;
  }
  function rangeForView(view, anchor, weekStart) {
    if (view === 'day') { const from = startOfDay(anchor); return { from, to: addDays(from, 1) }; }
    if (view === 'month') { const days = monthGridDays(anchor, weekStart); return { from: days[0].date, to: addDays(days[41].date, 1) }; }
    const from = startOfWeek(anchor, weekStart);
    return { from, to: addDays(from, 7) };
  }
  function daysInRange(range) {
    const out = [];
    for (let d = range.from; d < range.to; d = addDays(d, 1)) out.push(d);
    return out;
  }
  function shiftAnchor(view, anchor, dir) {
    if (view === 'day') return addDays(anchor, dir);
    if (view === 'month') return addMonths(anchor, dir);
    return addDays(anchor, 7 * dir);
  }
  function windowFor(range) { return { from: addDays(range.from, -31), to: addDays(range.to, 31) }; }
  function coversRange(cache, range) { return !!cache && cache.from <= range.from && range.to <= cache.to; }
  function isToday(d, now) { return startOfDay(d).getTime() === startOfDay(now).getTime(); }

  function formatRangeTitle(view, anchor, range, lang) {
    const ja = lang === 'ja';
    if (view === 'month') {
      return ja ? `${anchor.getFullYear()}年${anchor.getMonth() + 1}月`
        : new Intl.DateTimeFormat('en-US', { year: 'numeric', month: 'long' }).format(anchor);
    }
    if (view === 'day') {
      return ja ? `${anchor.getFullYear()}年${anchor.getMonth() + 1}月${anchor.getDate()}日(${WEEKDAYS_JA[anchor.getDay()]})`
        : new Intl.DateTimeFormat('en-US', { weekday: 'short', year: 'numeric', month: 'short', day: 'numeric' }).format(anchor);
    }
    const f = range.from, l = addDays(range.to, -1);
    if (ja) {
      if (f.getFullYear() !== l.getFullYear()) return `${f.getFullYear()}年${f.getMonth() + 1}月${f.getDate()}日〜${l.getFullYear()}年${l.getMonth() + 1}月${l.getDate()}日`;
      if (f.getMonth() !== l.getMonth()) return `${f.getFullYear()}年${f.getMonth() + 1}月${f.getDate()}日〜${l.getMonth() + 1}月${l.getDate()}日`;
      return `${f.getFullYear()}年${f.getMonth() + 1}月 ${f.getDate()}日〜${l.getDate()}日`;
    }
    const md = new Intl.DateTimeFormat('en-US', { month: 'short', day: 'numeric' });
    const mdy = new Intl.DateTimeFormat('en-US', { month: 'short', day: 'numeric', year: 'numeric' });
    if (f.getFullYear() !== l.getFullYear()) return `${mdy.format(f)} – ${mdy.format(l)}`;
    if (f.getMonth() !== l.getMonth()) return `${md.format(f)} – ${mdy.format(l)}`;
    return `${md.format(f)} – ${l.getDate()}, ${f.getFullYear()}`;
  }
```

```js
  // ---- レイアウト ----
  function isAllDayLike(ev) { return ev.allDay || ev.end - ev.start >= DAY_MS; }

  function segmentsByDay(events, days) {
    return days.map((day) => {
      const d0 = startOfDay(day), d1 = addDays(d0, 1);
      const allDay = [], timed = [];
      for (const ev of events) {
        if (ev.end <= d0 || ev.start >= d1) continue;
        if (isAllDayLike(ev)) { allDay.push(ev); continue; }
        timed.push({
          event: ev,
          start: ev.start > d0 ? ev.start : d0,
          end: ev.end < d1 ? ev.end : d1,
          continuesBefore: ev.start < d0,
          continuesAfter: ev.end > d1,
        });
      }
      timed.sort((a, b) => a.start - b.start || b.end - a.end);
      return { date: d0, allDay, timed };
    });
  }

  function allDayBars(events, days) {
    if (days.length === 0) return [];
    const first = startOfDay(days[0]);
    const endAll = addDays(startOfDay(days[days.length - 1]), 1);
    const bars = [];
    for (const ev of events) {
      if (!isAllDayLike(ev) || ev.end <= first || ev.start >= endAll) continue;
      const s = ev.start < first ? first : startOfDay(ev.start);
      const e = ev.end > endAll ? endAll : ev.end;
      const startCol = Math.round((s - first) / DAY_MS);
      const endCol = Math.min(days.length, Math.ceil((e - first) / DAY_MS));
      bars.push({ event: ev, startCol, span: Math.max(1, endCol - startCol), continuesLeft: ev.start < first, continuesRight: ev.end > endAll, row: 0 });
    }
    bars.sort((a, b) => a.startCol - b.startCol || b.span - a.span || a.event.start - b.event.start);
    const rows = []; // rows[r] = [[startCol, endCol), ...]
    for (const bar of bars) {
      const s = bar.startCol, e = bar.startCol + bar.span;
      let r = 0;
      for (;;) {
        const taken = rows[r] || (rows[r] = []);
        if (taken.every(([ts, te]) => s >= te || e <= ts)) { taken.push([s, e]); bar.row = r; break; }
        r++;
      }
    }
    return bars;
  }

  function layoutColumns(segs) {
    const sorted = [...segs].sort((a, b) => a.start - b.start || b.end - a.end);
    const out = [];
    let cluster = [], clusterEnd = null;
    const flush = () => {
      const colEnds = [];
      const placed = cluster.map((seg) => {
        let col = colEnds.findIndex((end) => end <= seg.start);
        if (col === -1) { col = colEnds.length; colEnds.push(seg.end); } else colEnds[col] = seg.end;
        return { seg, col };
      });
      for (const p of placed) out.push({ seg: p.seg, col: p.col, cols: colEnds.length });
      cluster = []; clusterEnd = null;
    };
    for (const seg of sorted) {
      if (clusterEnd !== null && seg.start >= clusterEnd) flush();
      cluster.push(seg);
      if (clusterEnd === null || seg.end > clusterEnd) clusterEnd = seg.end;
    }
    if (cluster.length) flush();
    return out;
  }

  function clipToHours(seg, dayStart, dayEnd) {
    const d0 = startOfDay(seg.start);
    const a = dayStart * 60, b = dayEnd * 60;
    const s = Math.round((seg.start - d0) / 60000), e = Math.round((seg.end - d0) / 60000);
    const top = Math.max(s, a), bottom = Math.min(e, b);
    if (bottom <= top) return null;
    return { topPct: ((top - a) / (b - a)) * 100, heightPct: ((bottom - top) / (b - a)) * 100, clippedTop: s < a, clippedBottom: e > b };
  }

  function monthCells(events, days, max) {
    const byDay = segmentsByDay(events, days.map((d) => (d instanceof Date ? d : d.date)));
    return byDay.map((d) => {
      const items = [
        ...d.allDay.map((ev) => ({ event: ev, allDay: true })),
        ...d.timed.map((seg) => ({ event: seg.event, allDay: false, start: seg.start })),
      ];
      return { date: d.date, items: items.slice(0, max), more: Math.max(0, items.length - max) };
    });
  }
```

```js
// CalendarEvent.getColor() は色番号("1"〜"11")を返すので 16 進に変換する
const EVENT_COLORS = {
  '1': '#a4bdfc', '2': '#7ae7bf', '3': '#dbadff', '4': '#ff887c', '5': '#fbd75b', '6': '#ffb878',
  '7': '#46d6db', '8': '#e1e1e1', '9': '#5484ed', '10': '#51b749', '11': '#dc2127',
};

function doGet(e) {
  const p = (e && e.parameter) || {};
  try {
    if (TOKEN && p.token !== TOKEN) return json({ ok: false, error: 'unauthorized' });
    const tz = Session.getScriptTimeZone();
    if (p.action === 'list') return json({ ok: true, tz: tz, generatedAt: iso(new Date(), tz), calendars: listCalendars() });
    const from = parseYmd(p.from), to = parseYmd(p.to);
    if (!from || !to || to <= from) return json({ ok: false, error: 'bad_request' });
    if ((to - from) / 86400000 > MAX_DAYS) return json({ ok: false, error: 'range_too_large' });
    const wanted = p.cal ? String(p.cal).split(',').map(function (s) { return s.trim(); }).filter(Boolean) : null;
    const calendars = wanted
      ? wanted.map(function (id) { return CalendarApp.getCalendarById(id) || { missing: id }; })
      : CalendarApp.getAllCalendars();
    const outCals = [], events = [], errors = [];
    calendars.forEach(function (c) {
      if (c.missing) { errors.push({ calendarId: c.missing, error: 'not_found' }); return; }
      const id = c.getId(), calColor = hex(c.getColor());
      outCals.push({ id: id, name: c.getName(), color: calColor });
      try {
        c.getEvents(from, to).forEach(function (ev) {
          const allDay = ev.isAllDayEvent();
          events.push({
            id: ev.getId(), calendarId: id, title: ev.getTitle(),
            start: allDay ? ymd(ev.getAllDayStartDate(), tz) : iso(ev.getStartTime(), tz),
            end: allDay ? ymd(ev.getAllDayEndDate(), tz) : iso(ev.getEndTime(), tz),
            allDay: allDay,
            location: ev.getLocation() || '',
            description: plainText(ev.getDescription() || ''),
            color: EVENT_COLORS[ev.getColor()] || calColor,
          });
        });
      } catch (err) {
        errors.push({ calendarId: id, error: String((err && err.message) || err) });
      }
    });
    return json({ ok: true, tz: tz, generatedAt: iso(new Date(), tz), calendars: outCals, events: events, errors: errors });
  } catch (err) {
    return json({ ok: false, error: 'internal', detail: String((err && err.message) || err) });
  }
}

function listCalendars() {
  return CalendarApp.getAllCalendars().map(function (c) { return { id: c.getId(), name: c.getName(), color: hex(c.getColor()) }; });
}
function parseYmd(s) {
  const m = /^(\d{4})-(\d{2})-(\d{2})$/.exec(String(s || ''));
  return m ? new Date(Number(m[1]), Number(m[2]) - 1, Number(m[3])) : null;
}
function iso(d, tz) { return Utilities.formatDate(d, tz, "yyyy-MM-dd'T'HH:mm:ssXXX"); }
function ymd(d, tz) { return Utilities.formatDate(d, tz, 'yyyy-MM-dd'); }
function hex(c) { const m = /^#?([0-9a-fA-F]{6})$/.exec(String(c || '')); return m ? '#' + m[1].toLowerCase() : ''; }
// 説明は HTML で返ることがあるのでタグを落として改行だけ残す
function plainText(s) {
  return String(s).replace(/<br\s*\/?>/gi, '\n').replace(/<\/p>/gi, '\n').replace(/<[^>]+>/g, '')
    .replace(/&nbsp;/g, ' ').replace(/&lt;/g, '<').replace(/&gt;/g, '>').replace(/&quot;/g, '"').replace(/&#39;/g, "'").replace(/&amp;/g, '&')
    .replace(/\n{3,}/g, '\n\n').trim();
}
function json(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj)).setMimeType(ContentService.MimeType.JSON);
}
```

# calendar

Google カレンダーの予定(複数カレンダー)を、日・週・月のいずれかで常時表示するページです。データは自分の Google アカウントで動く Google Apps Script(GAS)ウェブアプリから JSON で受け取ります(Google の iCal URL はブラウザから直接読めないため)。

## 機能

- 日 / 週 / 月表示(Google カレンダー風)。週の開始曜日、表示時刻範囲(既定 6:00〜23:00)を設定可
- 複数カレンダーを色分けして重ね表示。カレンダーごとに表示 / 非表示と色の上書き
- 重なる予定は横に分割。日をまたぐ予定は日ごとに分割。終日・複数日は終日帯に横棒
- 予定をタップすると時刻・場所・説明・カレンダー名をポップオーバー表示(編集はしない)
- 画面下のボタン(前 / 今日 / 翌、日 / 週 / 月)と左右フリックで移動。無操作が続くと今日に戻る(既定 5 分、0 で無効)
- 表示範囲の前後 1 か月をまとめて取得してキャッシュ。10 分ごとに自動更新(変更可)。失敗時は前回表示を保ち、ステータスに赤で理由
- 右上のアイコンでダーク/ライト、拡大/縮小、フルスクリーン、日英を切替。設定は右上の歯車

## 使い方

1. https://script.google.com で新しいプロジェクトを作り、`gas/Code.gs` の内容(設定画面の「接続」タブにも同じものがあります)を貼り付ける。必要なら先頭の `TOKEN` に任意の文字列を入れる。
2. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行ユーザー「自分」、アクセス「全員」でデプロイする。初回は権限の承認を求められる。
3. `index.html` をブラウザで開き、右上の歯車 → 「接続」タブに「ウェブアプリの URL」(`…/exec`)とトークンを入れ、「接続して一覧を取得」を押す。
4. 表示するカレンダーにチェックを入れる。祝日を出したいときは Google カレンダー側で「日本の祝日」を追加しておくと一覧に出る。
5. コードを変えたときは「デプロイを管理」から同じデプロイを新バージョンで更新する(URL は変わらない)。

URL とトークンはブラウザの localStorage に保存され、「データ」タブから書き出せます。URL を知っていれば誰でも予定を読めるので、iCal の秘密アドレスと同じ扱いにしてください。

### URL パラメータ

| パラメータ | 例 | 説明 |
|---|---|---|
| `view` | `view=month` | `day` / `week` / `month` |
| `date` | `date=2026-10-13` | 起動時の基準日(保存しない) |
| `weekStart` | `weekStart=1` | 0 = 日曜、1 = 月曜 |
| `dayStart`, `dayEnd` | `dayStart=8&dayEnd=20` | 表示時刻範囲(0〜23 / 1〜24) |
| `returnToTodayMinutes` | `returnToTodayMinutes=0` | 今日へ戻るまでの分(0 で無効) |
| `refreshMinutes` | `refreshMinutes=30` | 更新間隔(分、1〜120) |
| `gasUrl`, `token` | | 通常は設定画面から入れる |
| `lang` / `theme` / `zoom` | `zoom=120` | 共通 |
| `save` | `save=1` | URL の設定を localStorage に保存する |

## データの保存形式

localStorage キー `simplePages.calendar`:

```json
{ "version": 1, "settings": {
  "lang": "ja", "theme": "auto", "zoom": 100, "refreshMinutes": 10,
  "gasUrl": "https://script.google.com/macros/s/…/exec", "token": "",
  "calendars": [ { "id": "xxx@group.calendar.google.com", "name": "仕事", "color": "#039be5", "enabled": true } ],
  "view": "week", "weekStart": 0, "dayStart": 6, "dayEnd": 23, "returnToTodayMinutes": 5 } }
```

## GAS ウェブアプリの API

- `GET …/exec?action=list[&token=]` → `{ ok, tz, calendars: [{ id, name, color }] }`
- `GET …/exec?from=YYYY-MM-DD&to=YYYY-MM-DD[&cal=id1,id2][&token=]` → `{ ok, tz, calendars, events: [{ id, calendarId, title, start, end, allDay, location, description, color }], errors }`
  - `to` は排他的。終日予定の `start`/`end` は `YYYY-MM-DD`(`end` は翌日)。期間は最大 100 日。
- 失敗: `{ ok: false, error: "unauthorized" | "bad_request" | "range_too_large" | "internal" }`

## 既知の制約

- 予定の作成・編集・通知には対応しない。
- 時刻グリッドはスクロールしない。表示時刻範囲の外にかかる予定は端で切れる(範囲は設定で変更)。
- 月表示は 1 セルに入る件数だけ表示し、残りは「+N」。
- GAS の応答が HTML(認可画面)のときは「応答が JSON ではありません」と表示する。デプロイのアクセス設定を確認する。
