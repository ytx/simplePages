# time4u Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `time4u/`, a phone-first page for proposing meeting slots to clients: weekly availability bands, free-slot generation with holds, a copy-to-clipboard proposal message, and confirmation/release of held slots. All data lives in localStorage.

**Architecture:** One `time4u/index.html` started from `_template/index.html`. `Logic` holds pure functions over a plain data object (`clients / bands / blocks / proposals`): kana-normalized search, free-interval and slot arithmetic, spread picking, message building, calendar projections (day / week / month) and data normalization. `App` renders four bottom tabs (clients / week / month / settings) with sliding child views, page-internal dialogs, and persists settings in `simplePages.time4u` and data in `simplePages.time4u.data`. The settings UI is embedded in the settings tab instead of a modal. Zen Kurenaido is self-hosted from `time4u/fonts/`.

**Tech Stack:** Vanilla HTML/CSS/JS, `<dialog>` for page-internal sheets, Clipboard API with `execCommand('copy')` fallback, `node --test` (Node 20+).

**Spec:** `docs/superpowers/specs/2026-10-17-time4u-design.md`. Shared conventions: `docs/superpowers/specs/2026-10-12-simplepages-conventions-design.md`, `docs/superpowers/specs/2026-10-13-toolbar-and-settings-modal-design.md`. Reference for patterns (read-only): `l_timer/index.html` (page-internal `#dialog`, separate data key), `calendar/index.html` (swipe: `isSwipe`, window-level pointer tracking). Font source (read-only): `/Users/yt/git/green/packages/client/public/fonts/zen-kurenaido/` and `/Users/yt/git/green/packages/client/src/styles/fonts.css`.

## Global Constraints

- One page = `time4u/index.html`. No external `<link>`, `<script src>`, CDN. Same-directory media only: the 122 `fonts/zen-kurenaido/zk-NNN.woff2` files referenced by literal `url()` inside the inline `<style>`. No setting or URL string ever reaches `src`/`url()`.
- Exactly two globals: `Logic` (`<script id="app-logic">`, no DOM) and `App` (`<script id="app-ui">`).
- External strings (client names, titles, messages) go through `textContent` / `value`. **No `innerHTML` anywhere.**
- **No emoji anywhere in markup, CSS, or i18n strings.** Icons are Material Icons paths embedded as `<symbol>` + `<use>`. (User-editable templates may contain emoji; the shipped default templates do not.)
- Font: `--font: 'Zen Kurenaido', system-ui, -apple-system, "Segoe UI", Roboto, "Hiragino Sans", "Noto Sans JP", sans-serif`. Weight 400 only: **no `font-weight: bold/600+` anywhere**. Numbers use `font-variant-numeric: tabular-nums`.
- Settings: localStorage `simplePages.time4u` as `{ version: 1, settings }`. Data: `simplePages.time4u.data` as `{ version: 1, clients, bands, blocks, proposals }`. Priority URL query > localStorage > default; URL saved only with `?save=1`. Query `tab=clients|week|month|settings` selects the initial tab and is never saved.
- Every setting key is in `DISPLAY_ONLY_KEYS`; `refresh()` is a no-op; no fetch.
- Dates are local `'YYYY-MM-DD'` strings, times `'HH:MM'`; the only `Date` arithmetic is in `Logic.addDays` / `Logic.weekStartOf` / `Logic.todayStr` (noon-anchored). `App` passes `now` (a `Date`) into Logic.
- Expiry never releases anything automatically. Holds = slots of `status: 'pending'` proposals, regardless of deadline.
- Tap targets ≥ 44 px. `prefers-reduced-motion: reduce` disables slide transitions.
- Tests: `node --test time4u/test/*.test.mjs` (glob form; never a directory). No network in tests. `test/load-logic.mjs` copied from `_template/test/` (sets nothing; add `process.env.TZ = 'Asia/Tokyo'` at the top of each test file that touches dates).
- Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- i18n: every `data-i18n` / `data-i18n-label` / `data-i18n-placeholder` key and every `Logic.t(lang, '…')` key exists in both `ja` and `en`.

## Review Focus

Behaviours the spec implies but that are easy to miss. Each has a test in the owning task.

1. **Hold adjacent to a band edge**: band 13:00–17:00, hold 13:00–14:30, interval 10 → remaining slot is 14:40–16:10, never 14:30–16:00 (Task 4).
2. **Busy block does not add interval**: band 10:00–15:00, busy 12:00–13:00, 90 min, interval 10 → `10:00–11:30`, `13:00–14:30` (Task 4).
3. **Expired proposal still holds**: deadline yesterday, status pending → its slots are absent from `freeSlots` and present in `holds` (Task 4).
4. **Confirm releases the rest without touching other clients**: after confirming slot B of proposal P1, `freeSlots` returns P1's slots A and C again but still excludes proposal P2's slots (Task 4).
5. **Re-propose sees its own old slots**: `freeSlots(..., excludeProposalId = P1.id)` returns P1's held slots (Task 4).
6. **Deleting a client with history**: `normalizeData` drops blocks/proposals whose `clientId` no longer exists, so a corrupted store never crashes rendering (Task 3).
7. **Composition reading survives**: `matchesClient` matches `reading: 'たなか'` for queries `たな`, `タナ`, `ﾀﾅ` (Task 2).

### Task 2: Logic — dates, formatting, time-of-day, kana search

**Files:**

**Interfaces:**
- Produces (all on `Logic`):
  - `toMin(hhmm: string) → number`, `toHHMM(min: number) → string` (zero-padded, `24:00` allowed)
  - `todayStr(now: Date) → 'YYYY-MM-DD'` (local)
  - `addDays(date: string, n: number) → string`
  - `weekStartOf(date: string, weekStart: 0|1) → string`

  - `formatDateLong(date, lang) → '10月22日(木)' | 'Thu, Oct 22'`
  - `formatRange(start, end, lang) → '13:00〜14:30' | '13:00–14:30'`
  - `formatSlotLong(slot: {date,start,end}, lang) → formatDateLong + ' ' + formatRange`
  - `formatWeekTitle(weekStartDate, lang) → '10/19 – 10/25'`
  - `formatMonthTitle(year, month, lang) → '2026年10月' | 'October 2026'`
  - `isExpired(proposal, today) → boolean` (`today > proposal.deadline`, string compare)
  - `daysUntil(deadline, today) → number`

- [ ] **Step 3: Implement in `app-logic`**

`freeIntervals(data, date, interval, excludeProposalId)` algorithm (the spec fixes it):
1. Start from `mergeBands` of that day's bands as free intervals (in minutes).
2. Gather "spacing" occupiers = meeting blocks + `holds(data, excludeProposalId)` on that date, and "plain" occupiers = busy blocks.
3. Subtract every occupier from every free interval (splitting as needed).
4. For each resulting interval, if its start equals the end of a spacing occupier, add `interval`; if its end equals the start of a spacing occupier, subtract `interval`. Drop intervals with `end - start <= 0`.
5. Return sorted, as `HH:MM`.

`freeSlots`: for each date from `from` to `to` (inclusive) whose `weekdayOf` is in `weekdays`: for each interval, `for (t = start; t + slotMin <= end; t += slotMin + interval)` push the slot if `timeOfDay(toHHMM(t), settings)` is in `conditions.timeOfDay` and (`date > today` or `t > nowMin`). Sort by date then start.

`pickSpread(slots, selected, n)`: `out = [...selected]`; while `out.length < n` and candidates remain: for each candidate not in `out` (by `slotKey`), score = `(minimum |dayDiff| to any date in out, or Infinity when out is empty)`, tie-break 1 = time-of-day label not yet used in `out` (use fixed `pmStart 12 / eveStart 17` for this heuristic), tie-break 2 = earlier `slotKey`; push the best. Return `out`.

`buildMessage`: `parts = [header, slots.map(bullet + formatSlotLong).join('\n'), footer.replaceAll('{期限}', formatDateLong(deadline, lang))].filter(p => p.length > 0).join('\n\n')`; bullet `・` for ja, `- ` for en.
