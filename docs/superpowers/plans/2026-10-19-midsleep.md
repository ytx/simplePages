# midsleep Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A phone-first single-file page `midsleep/index.html` that records bed/wake times with one tap, computes a target mid-sleep time from recent records, tells the user when to wake if they sleep now and when to go to bed to wake at a chosen time, and shows a history chart.

**Architecture:** One `index.html` following the simplePages conventions and the time4u shell (bottom tab bar, settings embedded in a tab, `dialog#sheet`, `dialog#dialog`, status bar, data tab). `<script id="app-logic">` holds pure functions (`Logic`): local-time parsing, circular mean, advice, stats, record validation, chart model. `<script id="app-ui">` (`App`) renders the three tabs from `Logic` output and persists to localStorage `simplePages.midsleep` (settings) and `simplePages.midsleep.data` (records).

**Tech Stack:** Vanilla HTML/CSS/JS, no build, Node 20+ `node:test` for `app-logic`, inline Material Icons SVG, PWA manifest + PNG icons (no service worker).

**Spec:** `docs/superpowers/specs/2026-10-19-midsleep-design.md` (read it; it is the authority). Conventions: `CLAUDE.md`, `docs/superpowers/specs/2026-10-12-simplepages-conventions-design.md`. Reference implementation to copy UI plumbing from: `time4u/index.html` and its spec `docs/superpowers/specs/2026-10-17-time4u-design.md`.

## Global Constraints

- One page = `midsleep/index.html`. No external `<link>`/`<script src>`/CDN/web fonts. Allowed same-directory files: `manifest.webmanifest`, `icons/*.png` (`<link rel="manifest">`, `apple-touch-icon`, `theme-color`).
- Only two globals: `Logic` (in `<script id="app-logic">`, no DOM) and `App` (in `<script id="app-ui">`).
- No `innerHTML`. External/user strings via `textContent`. SVG charts built with `document.createElementNS`.
- **No emoji anywhere in the UI.** Icons are Material Icons paths as inline `<symbol>` + `<use>`.
- No bold (`<b>`, `<strong>`, `font-weight` ≥ 600) in page UI text except where the time4u shell already uses it (help text is not part of this page). Big numbers use size, not weight.
- i18n: `Logic.I18N.ja` and `Logic.I18N.en` must have identical key sets; static strings via `data-i18n`; dynamic via `tr(key, params)`. Times are 24-hour `H:MM` (`0:08`, `23:40`) in both languages. Durations: ja `7 時間 19 分`, en `7 h 19 min`.
- Settings in localStorage `simplePages.midsleep` as `{ version: 1, settings }`; records in `simplePages.midsleep.data` as `{ version: 1, records }`. `DISPLAY_ONLY_KEYS` = every settings key. `refresh()` only re-renders.
- Local time strings are `YYYY-MM-DDTHH:MM` (no zone, minutes). All arithmetic via `Date` in local time; DST ignored.
- Settings keys and defaults (spec table): `chartDays` enum 14/30 default 14; `wakeTarget` string `HH:MM` default `06:00`; `avgDays` int 3–30 default 7; `minSleepMin` int 180–720 default 360; `staleHours` int 10–36 default 18; plus common `lang`, `theme`, `zoom`.
- Settings tab sections in order: 表示 / 計算 / データ / About. No 一般 section, no lang/theme/zoom inputs. Toolbar: dark/light, zoom in, zoom out, lang, settings(→ settings tab). No fullscreen button, no help button.
- Tabs `today` / `history` / `settings`; icons `bedtime`, `bar_chart`, `settings`. URL `?tab=` opens a tab (not saved).
- Tap targets ≥ 44 px; inputs `font-size: max(16px, var(--fs-base))` (iOS zoom guard); fields use `minmax(0,1fr)` + `width:100%` (iOS overflow guard, see time4u CSS `.field`).
- Tests: `node --test midsleep/test/*.test.mjs` (glob form; Node 24 rejects a directory argument). No network in tests. `process.env.TZ = 'Asia/Tokyo'` at the top of every test file that touches `Date`.
- Commit footer on every commit: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

## Review Focus

1. Opening the today tab at 14:00 with target 3:04: the "今寝ると" card must still render (wake 16:08 next day, `long` flag) and must not throw or show NaN. (Task 4 test `wakeFor daytime`, Task 6 manual.)
2. A record spanning midnight edited so that wake ≤ bed, or overlapping the open sleeping record: the sheet must disable Save with a reason, never save. (Task 3 tests `validateRecord`.)
3. Only one sleeping record: importing data with two `wakeAt: null` records keeps the newest only; the today tab never shows two states at once. (Task 3 test `normalizeData keeps latest sleeping`.)
4. Mid-sleep times straddling midnight (23:00 and 1:00) must average to 0:00, not 12:00, and ばらつき must be computed from circular differences. (Task 2 `circularMean`, Task 3 `stats sd`.)
5. Chart with a record whose bed is before 21:00 or wake after 9:00: axis expands to whole hours and bars stay inside the viewBox; naps draw thin bars without dots and the mid line skips them. (Task 5 tests `chartModel expands axis`, `naps`.)

### Task 4: Logic — advice (wakeFor, bedFor, nextOccurrence, flags)
