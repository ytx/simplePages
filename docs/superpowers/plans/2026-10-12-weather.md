# weather ページ実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `_template` をコピーして `weather/index.html` を作り、気象庁 JSON と Open-Meteo を併用して 1 地点の天気予報を横長 1 画面に常時表示する。

**Architecture:** `Logic`(`app-logic`)に API 正規化・集約・マージ・コード変換・地点推定の純粋関数を置き、fixture で `node --test` する。`App`(`app-ui`)は fetch と描画と設定タブ(地点検索)を担う。描画は共通モデル `{ current, hourly, daily, meta }` だけを見る。グラフはインライン SVG を手書きで描く。

**Tech Stack:** HTML/CSS/JavaScript(ES2020)、Node.js 20 以上の `node --test`。外部ライブラリなし。API は気象庁 bosai JSON、Open-Meteo Forecast、Open-Meteo Geocoding(すべて CORS `*`、キー不要)。

**Spec:** `docs/superpowers/specs/2026-10-12-weather-design.md`(共通規約: `docs/superpowers/specs/2026-10-12-simplepages-conventions-design.md`)

**前提:** `docs/superpowers/plans/2026-10-12-template-conventions.md` が完了していること(`_template/` と `CLAUDE.md` が存在する)。

## Global Constraints

- `weather/index.html` 単体で動作。外部 `<link>`/`<script src>`/CDN/Web フォント禁止。
- グローバルは `Logic` と `App` のみ。外部由来文字列は `textContent` で挿入。
- localStorage キー `simplePages.weather`、値 `{ "version": 1, "settings": {...} }`。
- 設定の優先順位 URL > localStorage > 既定値。URL は `?save=1` のときだけ保存。
- 時刻は API が返す JST の ISO 文字列(`YYYY-MM-DDTHH:MM`)をそのまま文字列として扱い、`Date` のタイムゾーン変換はしない。
- Open-Meteo クエリは仕様書の固定値: `timezone=Asia/Tokyo`, `forecast_days=7`, `current=temperature_2m,relative_humidity_2m,apparent_temperature,wind_speed_10m,wind_direction_10m,weather_code,is_day`, `hourly=temperature_2m,precipitation_probability,precipitation,weather_code`, `daily=temperature_2m_max,temperature_2m_min,weather_code,precipitation_probability_max`。
- 既定値: `refreshMinutes=10`, `hourlyStep=3`, `hourlyCount=16`, `dailyDays=7`。
- 片方の API が失敗しても、もう片方で描く。失敗時は前回モデルを保持する。
- テストはネットワークに依存しない(fixture を使う)。
- コミットメッセージ末尾に `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` を付ける。

## Review Focus

1. 気象庁の週間予報の `pops`/`tempsMin`/`tempsMax` に空文字 `""` が入る(初日など)。`null` にして Open-Meteo で補完する(Task 4、Task 6 のテスト)。
2. 現在時刻が Open-Meteo `hourly` の範囲外(取得後に長時間経過)なら時間別は空配列になり、描画は「--」を出して例外にしない(Task 5 のテスト、Task 9 の空配列描画)。
3. URL に `lat`/`lon` だけで `office`/`area` が無い場合、気象庁の取得をスキップして Open-Meteo だけで描く(Task 7 のテスト、Task 9 の分岐)。
4. 気象庁 JSON の `[1]`(週間)が無い府県や取得途中の欠落で `normalizeJma` が落ちない(Task 4 のテスト)。
5. 地名検索で 0 件のときヒントを出し、`admin1` が府県表に無い(海外地点)ときは気象庁区を「なし」にして保存できる(Task 10 の実装と手動確認)。

```js
  function jmaCodeToIcon(code) {
    const s = code === null || code === undefined ? '' : String(code);
    if (!/^[1-4]\d\d$/.test(s)) return 'unknown';
    if (JMA_THUNDER.has(s)) return 'thunder';
    if (JMA_HEAVY.has(s)) return 'rain-heavy';
    const head = s[0];
    const sub = s.slice(1);
    if (head === '3') return sub === '03' || sub === '14' ? 'sleet' : 'rain';
    if (head === '4') return sub === '03' || sub === '14' ? 'sleet' : 'snow';
    // 晴(1) / 曇(2)
    if (SUB_SLEET.has(sub)) return 'sleet';
    if (SUB_SNOW.has(sub)) return 'snow';
    if (SUB_RAIN.has(sub)) return 'rain-light';
    if (sub === '00') return head === '1' ? 'sunny' : 'cloudy';
    // 上記以外の副天気(時々曇り、後曇り など)は晴曇の混在として扱う
    return head === '1' ? 'sunny-cloudy' : 'cloudy-sunny';
```

```js
  function toNum(s) {
    if (s === null || s === undefined || s === '') return null;
    const n = Number(s);
    return Number.isFinite(n) ? n : null;
  }

  function cleanText(s) {
    return typeof s === 'string' ? s.replace(/　+/g, ' ').trim() : null;
  }

  function pickArea(series, code) {
    if (!series || !Array.isArray(series.areas) || series.areas.length === 0) return null;
    return series.areas.find((a) => a.area && a.area.code === code) || series.areas[0];
  }

  function normalizeJma(json, class10Code) {
    const main = Array.isArray(json) ? json[0] : null;
    const week = Array.isArray(json) ? json[1] : null;
    const out = { reportTime: main?.reportDatetime ?? null, areaName: null, days: [], pops: [], weekly: [] };
    if (!main || !Array.isArray(main.timeSeries)) return out;

    const ts0 = main.timeSeries[0];
    const a0 = pickArea(ts0, class10Code);
    if (a0) {
      out.areaName = a0.area?.name ?? null;
      out.days = (ts0.timeDefines || []).map((t, i) => {
        const code = a0.weatherCodes?.[i] ?? null;
        return {
          date: t.slice(0, 10),
          code,
          icon: jmaCodeToIcon(code),
          weather: cleanText(a0.weathers?.[i]),
          wind: cleanText(a0.winds?.[i]),
          wave: cleanText(a0.waves?.[i]),
        };
      });
    }

    const ts1 = main.timeSeries[1];
    const a1 = pickArea(ts1, class10Code);
    if (a1) {
      out.pops = (ts1.timeDefines || []).map((t, i) => ({ time: t.slice(0, 16), pop: toNum(a1.pops?.[i]) }));
    }

    if (week && Array.isArray(week.timeSeries)) {
      const w0 = week.timeSeries[0];
      const w1 = week.timeSeries[1];
      const wa = w0?.areas?.[0];
      const ta = w1?.areas?.[0];
      if (w0 && wa) {
        out.weekly = (w0.timeDefines || []).map((t, i) => {
          const code = wa.weatherCodes?.[i] ?? null;
          return {
            date: t.slice(0, 10),
            code,
            icon: jmaCodeToIcon(code),
            pop: toNum(wa.pops?.[i]),
            tMin: toNum(ta?.tempsMin?.[i]),
            tMax: toNum(ta?.tempsMax?.[i]),
          };
        });
      }
    }
    return out;
  }
```

```js
  function normalizeOpenMeteo(json) {
    const out = { current: null, hourly: [], daily: [] };
    if (!json || typeof json !== 'object') return out;
    const c = json.current;
    if (c && typeof c === 'object') {
      out.current = {
        time: c.time ?? null,
        temp: toNum(c.temperature_2m),
        humidity: toNum(c.relative_humidity_2m),
        apparent: toNum(c.apparent_temperature),
        windSpeed: toNum(c.wind_speed_10m),
        windDir: toNum(c.wind_direction_10m),
        code: toNum(c.weather_code),
        isDay: c.is_day === undefined ? true : Number(c.is_day) === 1,
      };
    }
    const h = json.hourly;
    if (h && Array.isArray(h.time)) {
      out.hourly = h.time.map((t, i) => ({
        time: t,
        temp: toNum(h.temperature_2m?.[i]),
        pop: toNum(h.precipitation_probability?.[i]),
        precip: toNum(h.precipitation?.[i]),
        code: toNum(h.weather_code?.[i]),
      }));
    }
    const d = json.daily;
    if (d && Array.isArray(d.time)) {
      out.daily = d.time.map((t, i) => {
        const code = toNum(d.weather_code?.[i]);
        return {
          date: t,
          code,
          icon: wmoCodeToIcon(code),
          tMax: toNum(d.temperature_2m_max?.[i]),
          tMin: toNum(d.temperature_2m_min?.[i]),
          pop: toNum(d.precipitation_probability_max?.[i]),
        };
      });
    }
    return out;
  }

  function aggregateHourly(hourly, step, nowIso, count) {
    if (!Array.isArray(hourly) || hourly.length === 0) return [];
    const nowHour = Number.parseInt(nowIso.slice(11, 13), 10);
    const startHour = Math.floor(nowHour / step) * step;
    const startKey = `${nowIso.slice(0, 10)}T${String(startHour).padStart(2, '0')}:00`;
    let i = hourly.findIndex((h) => h.time >= startKey);
    if (i < 0) return [];
    const out = [];
    while (out.length < count && i < hourly.length) {
      const chunk = hourly.slice(i, i + step);
      const pops = chunk.map((c) => c.pop).filter((p) => p !== null);
      const precip = chunk.reduce((s, c) => s + (c.precip ?? 0), 0);
      out.push({
        time: chunk[0].time,
        temp: chunk[0].temp,
        pop: pops.length ? Math.max(...pops) : null,
        precip: Math.round(precip * 10) / 10,
        icon: worstIcon(chunk.map((c) => wmoCodeToIcon(c.code))),
      });
      i += step;
    }
    return out;
  }
```

```js
Model = {
  current: { temp, humidity, apparent, windSpeed, windDir, isDay, icon, code, text, wind, wave },
  hourly:  [{ time, temp, pop, precip, icon, jmaPop: number|null }],
  daily:   [{ date, icon, tMax, tMin, pop, fromFallback: { icon, tMax, tMin, pop } }],
  meta:    { jmaReportTime, omTime, jmaOk, omOk },
```

- `hourly` は `aggregateHourly` の結果に、同じ `time` の気象庁 `pops` を `jmaPop` として付ける(無ければ `null`)。
- `daily` は今日から `days` 日。各項目は気象庁週間 → (アイコンのみ)気象庁 `days` → Open-Meteo の順で埋め、Open-Meteo で埋めたものは `fromFallback` を `true` にする。

```js
  function addDays(dateStr, n) {
    const [y, m, d] = dateStr.split('-').map(Number);
    return new Date(Date.UTC(y, m - 1, d + n)).toISOString().slice(0, 10);
  }

  function mergeForecast(jma, om, nowIso, opts) {
    const today = nowIso.slice(0, 10);
    const jmaToday = jma ? (jma.days.find((d) => d.date === today) || jma.days[0] || null) : null;
    const cur = om?.current ?? null;

    const current = {
      temp: cur?.temp ?? null,
      humidity: cur?.humidity ?? null,
      apparent: cur?.apparent ?? null,
      windSpeed: cur?.windSpeed ?? null,
      windDir: cur?.windDir ?? null,
      isDay: cur ? cur.isDay : true,
      code: cur?.code ?? null,
      icon: cur ? wmoCodeToIcon(cur.code) : (jmaToday ? jmaToday.icon : 'unknown'),
      text: jmaToday?.weather ?? null,
      wind: jmaToday?.wind ?? null,
      wave: jmaToday?.wave ?? null,
    };

    const popByTime = new Map((jma?.pops ?? []).map((p) => [p.time, p.pop]));
    const hourly = (om ? aggregateHourly(om.hourly, opts.step, nowIso, opts.count) : [])
      .map((h) => ({ ...h, jmaPop: popByTime.has(h.time) ? popByTime.get(h.time) : null }));

    const daily = [];
    for (let i = 0; i < opts.days; i++) {
      const date = addDays(today, i);
      const w = jma?.weekly.find((x) => x.date === date) ?? null;
      const jd = jma?.days.find((x) => x.date === date) ?? null;
      const o = om?.daily.find((x) => x.date === date) ?? null;
      const pick = (jVal, oVal) => (jVal !== null && jVal !== undefined ? [jVal, false] : [oVal ?? null, oVal !== null && oVal !== undefined]);
      const jIcon = w?.code ? w.icon : (jd?.code ? jd.icon : null);
      const [icon, fIcon] = pick(jIcon, o?.icon);
      const [tMax, fMax] = pick(w?.tMax, o?.tMax);
      const [tMin, fMin] = pick(w?.tMin, o?.tMin);
      const [pop, fPop] = pick(w?.pop, o?.pop);
      daily.push({ date, icon: icon ?? 'unknown', tMax, tMin, pop, fromFallback: { icon: fIcon, tMax: fMax, tMin: fMin, pop: fPop } });
    }

    return {
      current, hourly, daily,
      meta: { jmaReportTime: jma?.reportTime ?? null, omTime: cur?.time ?? null, jmaOk: !!jma, omOk: !!om },
    };
  }
```

```js
  function validLocation(obj) {
    if (!obj || typeof obj !== 'object') return null;
    const lat = toNum(obj.lat);
    const lon = toNum(obj.lon);
    if (lat === null || lon === null || Math.abs(lat) > 90 || Math.abs(lon) > 180) return null;
    const office = typeof obj.jmaOffice === 'string' && findOffice(obj.jmaOffice) ? obj.jmaOffice : null;
    const area = typeof obj.jmaClass10 === 'string' && /^\d{6}$/.test(obj.jmaClass10) ? obj.jmaClass10 : null;
    return {
      name: typeof obj.name === 'string' && obj.name ? obj.name : `${lat}, ${lon}`,
      lat, lon,
      jmaOffice: office,
      jmaClass10: office ? area : null,
      jmaClass10Name: typeof obj.jmaClass10Name === 'string' ? obj.jmaClass10Name : null,
    };
  }

  function locationFromQuery(query) {
    if (!query || query.lat === undefined || query.lon === undefined) return null;
    return validLocation({ name: query.name, lat: query.lat, lon: query.lon, jmaOffice: query.office, jmaClass10: query.area });
  }

  function jmaForecastUrl(office) {
    return `https://www.jma.go.jp/bosai/forecast/data/forecast/${office}.json`;
  }

  function openMeteoUrl(lat, lon) {
    const p = new URLSearchParams({
      latitude: String(lat), longitude: String(lon), timezone: 'Asia/Tokyo', forecast_days: '7',
      current: 'temperature_2m,relative_humidity_2m,apparent_temperature,wind_speed_10m,wind_direction_10m,weather_code,is_day',
      hourly: 'temperature_2m,precipitation_probability,precipitation,weather_code',
      daily: 'temperature_2m_max,temperature_2m_min,weather_code,precipitation_probability_max',
    });
    return `https://api.open-meteo.com/v1/forecast?${p}`;
  }

  function geocodingUrl(name) {
    const p = new URLSearchParams({ name, language: 'ja', count: '10' });
    return `https://geocoding-api.open-meteo.com/v1/search?${p}`;
  }

  function toLocalIso(d) {
    const z = (n) => String(n).padStart(2, '0');
    return `${d.getFullYear()}-${z(d.getMonth() + 1)}-${z(d.getDate())}T${z(d.getHours())}:${z(d.getMinutes())}`;
  }
```

```js
  let lastModel = null;

  async function fetchJson(url) {
    try {
      const r = await fetch(url, { cache: 'no-store' });
      if (!r.ok) return { ok: false, error: `HTTP ${r.status}` };
      return { ok: true, data: await r.json() };
    } catch (e) {
      return { ok: false, error: e.message || 'network' };
    }
  }

  function locale() { return settings.lang === 'ja' ? 'ja-JP' : 'en-US'; }

  function hourlyCount() {
    return Math.min(settings.hourlyCount, window.innerHeight < 900 ? 12 : 24);
  }

  async function refresh() {
    const loc = settings.location;
    $('#no-location').hidden = !!loc;
    for (const p of $$('.panel')) p.hidden = !loc;
    if (!loc) { setStatus('error', Logic.t(settings.lang, 'set_location_hint')); return; }

    setStatus('busy', Logic.t(settings.lang, 'updating'));
    const tasks = [fetchJson(Logic.openMeteoUrl(loc.lat, loc.lon))];
    if (loc.jmaOffice) tasks.push(fetchJson(Logic.jmaForecastUrl(loc.jmaOffice)));
    const [omRes, jmaRes] = await Promise.all(tasks);

    const errors = [];
    const om = omRes.ok ? Logic.normalizeOpenMeteo(omRes.data) : null;
    if (!omRes.ok) errors.push(`Open-Meteo: ${omRes.error}`);

    let jma = null;
    if (loc.jmaOffice) {
      if (jmaRes.ok) {
        jmaCache = { office: loc.jmaOffice, json: jmaRes.data };
      } else {
        errors.push(`JMA: ${jmaRes.error}`);
      }
      const cached = jmaCache && jmaCache.office === loc.jmaOffice ? jmaCache.json : null;
      if (cached) jma = Logic.normalizeJma(cached, loc.jmaClass10);
    }

    if (!om && !jma && lastModel) {
      setStatus('error', Logic.t(settings.lang, 'error_fetch', { reason: errors.join(' / ') }));
      return;
    }
    const nowIso = Logic.toLocalIso(new Date());
    lastModel = Logic.mergeForecast(jma, om, nowIso, { step: settings.hourlyStep, count: hourlyCount(), days: settings.dailyDays });
    render(lastModel);
    if (errors.length) setStatus('error', Logic.t(settings.lang, 'error_fetch', { reason: errors.join(' / ') }));
    else setStatus('ok', Logic.t(settings.lang, 'updated_at', { time: formatTime(new Date()) }));
```

# weather

設定した 1 地点の天気予報を、横長モニタやタブレットのブラウザ全画面に常時表示するページ。
`index.html` 単体で動き、API キーは不要。

## 機能

- 現在の天気: 気温、天気文言(気象庁)、湿度、体感温度、風、波
- 今日・明日の時間別: 気温の折れ線、降水確率と降水量の棒、天気アイコン(既定 3 時間刻み 16 コマ)
- 週間予報: 7 日分の天気、最高/最低気温、降水確率(気象庁。欠けは Open-Meteo で補完し薄く表示)
- 10 分ごとに自動更新(変更可)。失敗時は前回表示を保ち、ステータス帯に赤で理由を表示
- ダーク/ライト(自動/手動)、日本語/英語

## 使い方

1. `index.html` をブラウザで開く。
2. 右下の歯車 → 「地点」タブで地名を検索(例: 千葉市、新宿)し、候補を選ぶ。
3. 気象庁の府県予報区と一次細分区域が自動で入る。外れていればプルダウンで直す。
4. 常時表示端末では、設定済みの URL をブックマークするか、`?...&save=1` で一度保存する。

### URL パラメータ

| パラメータ | 例 | 説明 |
|---|---|---|
| `lat`, `lon` | `lat=35.6&lon=140.12` | 緯度経度(両方必須で地点を上書き) |
| `office` | `office=120000` | 気象庁 府県予報区コード |
| `area` | `area=120010` | 気象庁 一次細分区域コード |
| `name` | `name=千葉市` | 表示名 |
| `refreshMinutes` | `refreshMinutes=30` | 更新間隔(分、1〜120) |
| `hourlyStep` | `hourlyStep=1` | 時間別の刻み(1 または 3) |
| `hourlyCount` | `hourlyCount=12` | 時間別のコマ数(6〜24) |
| `dailyDays` | `dailyDays=5` | 週間の日数(5〜7) |
| `lang` | `lang=en` | `ja` / `en` |
| `theme` | `theme=dark` | `auto` / `light` / `dark` |
| `save` | `save=1` | URL の設定を localStorage に保存する |

優先順位は URL > localStorage > 既定値。

## データの保存形式

localStorage キー `simplePages.weather`:

```json
  "version": 1,
  "settings": {
    "lang": "ja", "theme": "auto", "refreshMinutes": 10,
    "hourlyStep": 3, "hourlyCount": 16, "dailyDays": 7,
    "location": { "name": "千葉市", "lat": 35.6, "lon": 140.11667, "jmaOffice": "120000", "jmaClass10": "120010", "jmaClass10Name": "北西部" }
  }
}
```

## 使用 API

| API | 用途 | 備考 |
|---|---|---|
| 気象庁 `https://www.jma.go.jp/bosai/forecast/data/forecast/<office>.json` | 天気文言、風、波、3 時間ごとの降水確率、週間予報 | キー不要、CORS 可。日本国内のみ。湿度は含まれない |
| Open-Meteo `https://api.open-meteo.com/v1/forecast` | 現在値、時間別、日別 | キー不要、CORS 可。非商用無料枠 1 日 1 万回 |
| Open-Meteo Geocoding `https://geocoding-api.open-meteo.com/v1/search` | 地名検索 | 日本語可。短い語(「千葉」)は 0 件になることがあるので市区町村名まで入力する |

気象庁の府県予報区表 `JMA_OFFICES` は `tools/gen-jma-offices.mjs` で `area.json` から生成したものを埋め込んでいる。更新するときは `node weather/tools/gen-jma-offices.mjs` の出力で置き換える。
