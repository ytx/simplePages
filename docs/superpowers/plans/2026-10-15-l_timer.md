# l_timer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `l_timer/`, a lecture timer page (lecture / break cycle with warning, end and overtime sounds, an independent exercise sub-timer, and a side note editor), porting the features of the stand-alone `/Users/yt/git/l_timer` app into the simplePages conventions.

**Architecture:** One `l_timer/index.html` started from `k_timer/index.html` (the closest existing page: same toolbar, settings dialog, audio handling). `Logic` holds two pure state machines (`MainState` for lecture/break, `ExerciseState` for the exercise timer) whose `tick*` functions return `{ state, events }` where `events` name the sounds to play, plus formatters and the document model (block JSON) with the legacy Quill importer. `App` renders every 250 ms, plays three `<audio>` elements, hosts a `contenteditable` editor rendered from blocks via DOM construction only, and stores settings in `simplePages.l_timer` and documents in `simplePages.l_timer.data`.

**Tech Stack:** Vanilla HTML/CSS/JS, `<audio>`, Web Audio API (beep fallback), `contenteditable` + `document.execCommand`, `node --test` (Node 20+).

**Spec:** `docs/superpowers/specs/2026-10-15-l_timer-design.md`. Shared conventions: `docs/superpowers/specs/2026-10-12-simplepages-conventions-design.md`, `docs/superpowers/specs/2026-10-13-toolbar-and-settings-modal-design.md`. Reference implementation to port: `/Users/yt/git/l_timer` (read-only; never modify it).

## Global Constraints

- One page = `l_timer/index.html`. No external `<link>`, `<script src>`, CDN or web fonts. Only same-directory media (`audio/*.wav`) may be referenced, and only through the constant map `Logic.SOUND_FILES`; never put a setting or URL string into `src`.
- Exactly two globals: `Logic` (in `<script id="app-logic">`, no DOM) and `App` (in `<script id="app-ui">`).
- External strings go through `textContent`. **No `innerHTML` anywhere**, including the editor: blocks are rendered with `createElement` / `textContent`.
- Settings: localStorage `simplePages.l_timer` as `{ version: 1, settings }`. Documents / draft / exercise titles: localStorage `simplePages.l_timer.data` as `{ version: 1, documents, draft, exerciseTitles }`. Priority URL query > localStorage > default. URL saved only with `?save=1`.
- All setting keys are display-only (`DISPLAY_ONLY_KEYS` holds every key). `refresh()` is an empty no-op. No fetch anywhere.
- Timer state is never persisted. Reload → idle. Draft and documents are persisted.
- No keyboard shortcuts. No `prompt` / `alert`; `confirm` only for the data tab's "clear all".
- Settings tabs: 表示 / タイマー / 音 / データ / About (no 一般 tab). Timer tab is a 2-column grid of 7 number fields, no scrolling.
- Below 700 px width: timer pane above editor pane, resizer hidden.
- Editor formatting: bold, bullet list, heading only. Editor zoom levels `75, 100, 150, 200, 300, 400` (%). Paste inserts plain text.
- `ADJUST_STEPS = [-10, -1, 1, 10]` (minutes). End-time adjustments floor the result to the minute (`floorToMinute`), never move an end time to the past unless already in overtime.
- Sound events are computed from thresholds crossed between the previous tick and now, so a background tab never misses a sound and never fires one twice.
- Tests: `node --test l_timer/test/*.test.mjs` (glob form; never a directory). No network. `test/load-logic.mjs` sets `TZ=Asia/Tokyo`.
- Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- i18n: every `data-i18n` / `data-i18n-label` / `data-i18n-placeholder` / `Logic.t(settings.lang, '…')` key exists in both `ja` and `en`.

## Review Focus

Behaviours the spec implies but that are easy to miss. Each has a test in the owning task.

1. **Warning after an extension**: lecture at 2:00 remaining (warning already fired), `+10` → the warning must fire again at the new 3:00 mark, and `end` must fire again at the new end (Task 2).
2. **Exercise paused in overtime**: pause at `-0:30`, resume 10 minutes later → still overtime at `-0:30`, not `-10:30`, and no `end` event fires again (Task 3).
3. **Draft pointing at a deleted document**: `data.draft.documentId` not in `documents` → treated as a new document, never a crash (Task 5).
4. **Legacy HTML with `<p><br></p>` blank lines and nested lists**: blank paragraphs survive as empty blocks, nested `<li>` flatten to consecutive `li` blocks, unknown tags (`<span style>`) vanish without eating their text (Task 5).
5. **Import of a legacy export must not drop existing documents**: import appends documents and regenerates colliding ids (Task 5).
6. **Break shorter than the warning**: `break1 = 2`, `warning = 3` → no warning sound at break start (threshold before `startedAt`) (Task 2).

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { readFileSync, openSync, readSync, closeSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { loadLogic } from './load-logic.mjs';

const here = (p) => fileURLToPath(new URL(p, import.meta.url));
const Logic = loadLogic(here('../index.html'));

test('every SOUND_FILES entry exists under l_timer/ and is a RIFF/WAVE file', () => {
  assert.equal(Object.keys(Logic.SOUND_FILES).length, 9);
  for (const rel of Object.values(Logic.SOUND_FILES)) {
    const fd = openSync(here(`../${rel}`), 'r');
    const buf = Buffer.alloc(12);
    readSync(fd, buf, 0, 12, 0);
    closeSync(fd);
    assert.equal(buf.toString('ascii', 0, 4), 'RIFF', rel);
    assert.equal(buf.toString('ascii', 8, 12), 'WAVE', rel);
  }
});

test('no sound file is referenced by a path outside SOUND_FILES', () => {
  const src = readFileSync(here('../index.html'), 'utf8');
  const refs = [...src.matchAll(/audio\/sound[^"'`\s]+/g)].map((m) => m[0]);
  const allowed = new Set(Object.values(Logic.SOUND_FILES));
  assert.ok(refs.length >= 9);
  for (const r of refs) assert.ok(allowed.has(r), r);
});
```

```js
  function initialMain() {
    return { mode: 'idle', breakType: null, startedAt: null, endAt: null, totalMs: 0, overtime: false, lastTickAt: null };
  }

  function startLecture(_s, now, minutes) {
    const ms = minutes * 60000;
    return { mode: 'lecture', breakType: null, startedAt: now, endAt: now + ms, totalMs: ms, overtime: false, lastTickAt: now };
  }

  function startBreak(_s, now, type, minutes) {
    const ms = minutes * 60000;
    return { mode: 'break', breakType: type, startedAt: now, endAt: now + ms, totalMs: ms, overtime: false, lastTickAt: now };
  }

  function stopMain(_s) { return initialMain(); }

  // ローカル時刻の秒・ミリ秒を 0 にする
  function floorToMinute(ms) {
    const d = new Date(ms);
    d.setSeconds(0, 0);
    return d.getTime();
  }

  // 終了時刻を deltaMin 分動かし、秒を 00 にする。過去にはしない(超過中だけは過去も許す)。
  function adjustEnd(s, deltaMin, now) {
    if (s.mode === 'idle') return s;
    const endAt = floorToMinute(s.endAt + deltaMin * 60000);
    const canBePast = s.mode === 'lecture' && s.overtime;
    if (endAt <= now && !canBePast) return s;
    return { ...s, endAt, overtime: s.mode === 'lecture' && endAt <= now };
  }

  // prev < t <= now を「閾値 t を跨いだ」とする。背景タブで数分飛んでも各 1 回だけ。
  function thresholdEvents(prev, now, startedAt, endAt, warningMin, tickSec) {
    const warnAt = endAt - warningMin * 60000;
    const warning = warnAt > startedAt && prev < warnAt && warnAt <= now;
    const end = prev < endAt && endAt <= now;
    const tickMs = tickSec * 1000;
    const tick = now - endAt >= tickMs && Math.floor((now - endAt) / tickMs) > Math.floor((prev - endAt) / tickMs);
    return { warning, end, tick };
  }

  function tickMain(s, now, warningMin, tickSec) {
    if (s.mode === 'idle') return { state: s, events: [] };
    const ev = thresholdEvents(s.lastTickAt, now, s.startedAt, s.endAt, warningMin, tickSec);
    const events = [];
    let overtime = s.overtime;
    if (ev.warning) events.push('warning');
    if (ev.end) {
      events.push('end');
      if (s.mode === 'lecture') overtime = true;
      else events.push('break_end');
    }
    if (s.mode === 'lecture' && overtime && ev.tick) events.push('tick');
    return { state: { ...s, overtime, lastTickAt: now }, events };
  }

  function remainingMain(s, now) {
    return s.mode === 'idle' ? null : s.endAt - now;
  }
```

```js
  const EXERCISE_MAX = 120;
  const MAX_TITLES = 20;
  const DEFAULT_EXERCISE_TITLE = '演習';
  const clampMin = (m) => Math.min(EXERCISE_MAX, Math.max(EXERCISE_MIN, m));

  function initialExercise(defaultMin, nextDefaultMin) {
    return { phase: 'none', title: '', setupMinutes: clampMin(defaultMin), startedAt: null, endAt: null, totalMs: 0, remainingMs: null, overtime: false, lastTickAt: null,
      next: { title: '', minutes: clampMin(nextDefaultMin) }, nextOpen: false };
  }

  function exerciseOpenSetup(e, defaultMin) {
    return { ...e, phase: 'setup', setupMinutes: clampMin(defaultMin), title: '' };
  }

  function exerciseAdjustSetup(e, deltaMin) {
    return { ...e, setupMinutes: clampMin(e.setupMinutes + deltaMin) };
  }

  function exerciseCancelSetup(e) { return { ...e, phase: 'none' }; }

  function exerciseStart(e, now, title, minutes, nextDefaultMin) {
    const ms = clampMin(minutes) * 60000;
    const t = String(title ?? '').trim() || DEFAULT_EXERCISE_TITLE;
    return { ...e, phase: 'running', title: t, startedAt: now, endAt: now + ms, totalMs: ms, remainingMs: null, overtime: false, lastTickAt: now,
      next: { title: '', minutes: clampMin(nextDefaultMin) }, nextOpen: false };
  }

  function exerciseStop(e) {
    return { ...initialExercise(e.setupMinutes, e.next.minutes) };
  }

  // running: 終了時刻を動かす(adjustEnd と同じ規則)。paused: 保持している残りを動かす。
  function exerciseAdjust(e, deltaMin, now) {
    if (e.phase === 'running') {
      const endAt = floorToMinute(e.endAt + deltaMin * 60000);
      if (endAt <= now && !e.overtime) return e;
      return { ...e, endAt, overtime: endAt <= now };
    }
    if (e.phase === 'paused') {
      const remainingMs = e.remainingMs + deltaMin * 60000;
      return { ...e, remainingMs, overtime: remainingMs <= 0 };
    }
    return e;
  }

  // 休憩開始で一時停止。残り(超過中は負)を保持し、終了時刻は捨てる。
  function exercisePause(e, now) {
    if (e.phase !== 'running') return e;
    return { ...e, phase: 'paused', remainingMs: e.endAt - now, endAt: null };
  }

  // 講義再開で再開。保持した残りから新しい終了時刻を作る。
  function exerciseResume(e, now) {
    if (e.phase !== 'paused') return e;
    return { ...e, phase: 'running', endAt: now + e.remainingMs, remainingMs: null, lastTickAt: now, overtime: e.remainingMs <= 0 };
  }

  function exerciseSetNext(e, title, minutes) {
    return { ...e, next: { title: String(title ?? ''), minutes: clampMin(minutes) } };
  }

  function exerciseAdjustNext(e, deltaMin) {
    return { ...e, next: { ...e.next, minutes: clampMin(e.next.minutes + deltaMin) } };

  function exerciseToggleNext(e, open) { return { ...e, nextOpen: !!open }; }

  function tickExercise(e, now, warningMin, tickSec) {
    if (e.phase !== 'running') return { state: e, events: [] };
    const ev = thresholdEvents(e.lastTickAt, now, e.startedAt, e.endAt, warningMin, tickSec);
    const events = [];
    if (ev.warning) events.push('warning');
    let state = { ...e, lastTickAt: now };
    if (ev.end) {
      events.push('end');
      if (e.next.title.trim()) {
        events.push('next_started');
        return { state: exerciseStart(e, now, e.next.title, e.next.minutes, e.next.minutes), events };
      }
      state.overtime = true;
    }
    if (state.overtime && ev.tick) events.push('tick');
    return { state, events };
  }

  function remainingExercise(e, now) {
    if (e.phase === 'running') return e.endAt - now;
    if (e.phase === 'paused') return e.remainingMs;
    return null;
  }

  function canStartExercise(main, e) {
    return main.mode === 'lecture' && e.phase === 'none';
  }

  // 演習中でも講義側のボタンは隠さない
  function buttonVisibility(main, e) {
    return {
      lecture: main.mode === 'idle',
      lectureFromBreak: main.mode === 'break',
      break1: main.mode !== 'break',
      break2: main.mode !== 'break',
      stop: main.mode !== 'idle',
      exercise: canStartExercise(main, e),
    };
  }

  function pageTitleKey(main) {
    if (main.mode === 'lecture') return main.overtime ? 'title_overtime' : 'title_lecture';
    if (main.mode === 'break') return 'title_break';
    return 'title_idle';
  }

  function addTitle(list, title) {

    if (!t2 || t2 === DEFAULT_EXERCISE_TITLE) return list.slice();
    return [t2, ...list.filter((x) => x !== t2)].slice(0, MAX_TITLES);
```

```js
  // 残り時間: 正は切り上げ(1 秒残っている間は 00:01)、超過は切り捨てで '+MM:SS'。超過 1 秒未満は 00:00。

    if (over && sec === 0) over = false;
    return `${over ? '+' : ''}${pad2(Math.floor(sec / 60))}:${pad2(sec % 60)}`;

  function formatEndAt(endAt) {
    if (endAt === null || endAt === undefined) return '--:--:--';
    const d = new Date(endAt);
    return `${pad2(d.getHours())}:${pad2(d.getMinutes())}:${pad2(d.getSeconds())}`;
  }

  // 進捗率(%)。超過は 100、分母が無ければ 0。
  function progress(totalMs, remainingMs) {

    if (!(remainingMs > 0)) return 100;
    return Math.min(100, Math.max(0, ((totalMs - remainingMs) / totalMs) * 100));
  }
```

```js
  // ---- 文書モデル: ブロック構造の JSON。表示は DOM 生成だけで行い innerHTML は使わない ----
  const BLOCK_TYPES = ['p', 'h', 'li'];
  const emptyRun = () => ({ text: '', bold: false });
  function emptyBlocks() { return [{ type: 'p', runs: [emptyRun()] }]; }

  function normalizeRun(r) {
    if (typeof r === 'string') return { text: r, bold: false };
    if (!r || typeof r !== 'object') return null;
    return { text: typeof r.text === 'string' ? r.text : String(r.text ?? ''), bold: r.bold === true };
  }

  function normalizeBlock(b) {
    if (typeof b === 'string') return { type: 'p', runs: [{ text: b, bold: false }] };
    const type = b && BLOCK_TYPES.includes(b.type) ? b.type : 'p';
    const runs = Array.isArray(b && b.runs) ? b.runs.map(normalizeRun).filter(Boolean) : [];
    return { type, runs: runs.length ? runs : [emptyRun()] };
  }

  function normalizeBlocks(value) {
    if (!Array.isArray(value) || value.length === 0) return emptyBlocks();
    return value.map(normalizeBlock);
  }

  function blocksToPlainText(blocks) {
    return blocks.map((b) => b.runs.map((r) => r.text).join('')).join('\n');
  }

  function firstLine(blocks, max = 50) {
    for (const line of blocksToPlainText(blocks).split('\n')) {
      const s = line.trim();
      if (s) return s.slice(0, max);
    }
    return '';
  }

  const isoOr = (v, fallback) => (typeof v === 'string' && v ? v : fallback);

  function normalizeDocument(d, now) {
    if (!d || typeof d !== 'object') return null;
    const iso = new Date(now).toISOString();
    return {
      id: typeof d.id === 'string' && d.id ? d.id : `doc_${now}`,
      title: String(d.title ?? ''),
      blocks: normalizeBlocks(d.blocks),
      createdAt: isoOr(d.createdAt, iso),
      updatedAt: isoOr(d.updatedAt, iso),
    };
  }

  function normalizeTitles(list) {
    if (!Array.isArray(list)) return [];
    const out = [];
    for (const t2 of list) {
      if (typeof t2 !== 'string' || !t2.trim() || out.includes(t2)) continue;
      out.push(t2);
      if (out.length >= MAX_TITLES) break;
    }
    return out;
  }

  // localStorage `simplePages.l_timer.data` の正規化。壊れていても落ちない。
  function normalizeData(raw, now = Date.now()) {
    const r = raw && typeof raw === 'object' ? raw : {};
    const documents = Array.isArray(r.documents) ? r.documents.map((d) => normalizeDocument(d, now)).filter(Boolean) : [];
    let draft = null;
    if (r.draft && typeof r.draft === 'object' && Array.isArray(r.draft.blocks)) {
      const id = typeof r.draft.documentId === 'string' && documents.some((d) => d.id === r.draft.documentId) ? r.draft.documentId : null;
      draft = { documentId: id, blocks: normalizeBlocks(r.draft.blocks), updatedAt: isoOr(r.draft.updatedAt, new Date(now).toISOString()) };
    }
    return { version: DATA_VERSION, documents, draft, exerciseTitles: normalizeTitles(r.exerciseTitles) };
  }

  // ---- 旧 l_timer(Quill)からの取り込み。DOM を使わない簡易トークナイザ ----
  const ENTITIES = { amp: '&', lt: '<', gt: '>', quot: '"', apos: "'", nbsp: ' ' };
  function decodeEntities(s) {
    return s.replace(/&(#x([0-9a-f]+)|#(\d+)|([a-z]+));/gi, (m, _g, hex, dec, name) => {
      if (hex) return String.fromCodePoint(parseInt(hex, 16));
      if (dec) return String.fromCodePoint(parseInt(dec, 10));
      const v = ENTITIES[name.toLowerCase()];
      return v === undefined ? m : v;
    });
  }

  function importLegacyHtml(html) {
    const blocks = [];
    let cur = null;
    let type = 'p';
    let bold = 0;
    const flush = () => { if (cur) blocks.push(cur); cur = null; };
    const ensure = () => { if (!cur) cur = { type, runs: [] }; };
    const addText = (txt) => {
      if (!txt) return;
      if (!cur && !txt.trim()) return; // ブロック間の空白は捨てる
      ensure();
      const b = bold > 0;
      const last = cur.runs[cur.runs.length - 1];
      if (last && last.bold === b) last.text += txt;
      else cur.runs.push({ text: txt, bold: b });
    };
    for (const m of String(html ?? '').matchAll(/<\/?([a-zA-Z][a-zA-Z0-9]*)[^>]*>|[^<]+/g)) {
      if (m[1] === undefined) { addText(decodeEntities(m[0].replace(/\s+/g, ' '))); continue; }
      const tag = m[1].toLowerCase();
      const closing = m[0].startsWith('</');
      if (tag === 'br') { ensure(); flush(); continue; }
      if (tag === 'strong' || tag === 'b') { bold = Math.max(0, bold + (closing ? -1 : 1)); continue; }
      if (/^h[1-6]$/.test(tag) || tag === 'li') {
        flush();
        type = closing ? 'p' : (tag === 'li' ? 'li' : 'h');
        if (!closing) ensure();
        continue;
      }
      if (tag === 'p' || tag === 'div' || tag === 'blockquote' || tag === 'pre') {
        flush();
        if (!closing) { type = 'p'; ensure(); }
        continue;
      }
      // ul / ol / span / em / その他: タグだけ捨てる
    }
    flush();
    return blocks.length ? blocks.map(normalizeBlock) : emptyBlocks();

  function isLegacyExport(obj) {
    return !!(obj && typeof obj === 'object' && typeof obj.version === 'string' && obj.settings && typeof obj.settings === 'object');

  const LEGACY_INT_KEYS = [['lectureTime', 'lecture'], ['break1Time', 'break1'], ['break2Time', 'break2'], ['warningTime', 'warning'], ['tickInterval', 'tick'], ['defaultExerciseTime', 'exercise'], ['defaultNextExerciseTime', 'nextExercise']];

    const es = (obj.settings && obj.settings.editorSettings) || {};
    const settings = {};
    for (const [from, to] of LEGACY_INT_KEYS) if (Number.isFinite(ts[from])) settings[to] = Math.round(ts[from]);
```

```js
  function soundKey(group) {

    return Logic.SOUND_GROUPS[group].includes(k) ? k : Logic.SOUND_GROUPS[group][0];
  }

  function loadSounds() {
    let changed = false;
    for (const group of Object.keys(AUDIO_ID)) {
      const a = $(AUDIO_ID[group]);
      const key = soundKey(group);
      if (a.dataset.sound === key) continue;
      a.dataset.sound = key;
      a.dataset.unlocked = '';
      a.src = Logic.SOUND_FILES[key];
      a.load();
      changed = true;
    }
    if (changed && audioBroken) { audioBroken = false; setStatus('ok', ''); }

  function markAudioBroken() {
    if (audioBroken) return;
    audioBroken = true;
    setStatus('error', () => Logic.t(settings.lang, 'error_audio'));
  }

  // 880 Hz 0.2 秒のビープ 1 回(読込失敗・自動再生拒否の代替)
  function beep() {
    if (!audioCtx || settings.muted || settings.volume === 0) return;
    const osc = audioCtx.createOscillator();
    const gain = audioCtx.createGain();
    osc.type = 'square';
    osc.frequency.value = 880;
    gain.gain.value = 0.3 * (settings.volume / 100);
    osc.connect(gain).connect(audioCtx.destination);
    osc.start();
    osc.stop(audioCtx.currentTime + 0.2);
  }

  // ユーザー操作(開始ボタン)の中で一度だけ無音再生し、後の play() が自動再生制限で拒否されないようにする
  function unlockAudio() {
    if (!audioCtx && window.AudioContext) {
      try { audioCtx = new AudioContext(); } catch { audioCtx = null; }
    }
    if (audioCtx && audioCtx.state === 'suspended') audioCtx.resume().catch(() => {});
    if (audioBroken) return;
    for (const sel of Object.values(AUDIO_ID)) {
      const a = $(sel);
      if (a.dataset.unlocked === '1') continue;
      a.muted = true;
      a.play().then(() => {
        a.dataset.unlocked = '1';
        a.muted = false;
        a.pause();
        a.currentTime = 0;
      }).catch(() => { a.muted = false; });
    }
```

```js
      let el;
      if (b.type === 'li') {
        if (!ul) { ul = document.createElement('ul'); frag.appendChild(ul); }
        el = document.createElement('li');

          s.textContent = r.text;
          el.appendChild(s);
        } else {

  // DOM → blocks。H1〜H6 → h、UL/OL の LI → li、それ以外のブロック → p。STRONG/B/font-weight>=600 を bold。
  function readBlocks() {
    const root = editorEl();
    const blocks = [];
    const isBold = (node) => {
      for (let n = node; n && n !== root; n = n.parentNode) {
        if (n.nodeType !== 1) continue;
        if (n.tagName === 'STRONG' || n.tagName === 'B') return true;
        const fw = n.style && n.style.fontWeight;
        if (fw === 'bold' || Number(fw) >= 600) return true;
      }
      return false;
    };
    const isList = (n) => n.nodeType === 1 && (n.tagName === 'UL' || n.tagName === 'OL');
    const pushBlock = (type, el) => {
      const runs = [];
      const walk = (node) => {
        for (const c of node.childNodes) {
          if (c.nodeType === 3) {
            if (!c.nodeValue) continue;
            const b = isBold(c);
            const last = runs[runs.length - 1];
            if (last && last.bold === b) last.text += c.nodeValue;
            else runs.push({ text: c.nodeValue, bold: b });
          } else if (c.nodeType === 1 && c.tagName !== 'BR' && !isList(c)) {
            walk(c);
          }
        }
      };
      walk(el);
      blocks.push({ type, runs });
    };
    const visit = (node) => {
      for (const c of node.childNodes) {
        if (c.nodeType === 3) { if (c.nodeValue.trim()) blocks.push({ type: 'p', runs: [{ text: c.nodeValue, bold: false }] }); continue; }
        if (c.nodeType !== 1) continue;
        if (isList(c)) {
          for (const li of c.children) {
            if (li.tagName !== 'LI') continue;
            pushBlock('li', li);
            for (const sub of li.children) if (isList(sub)) visit(sub); // 入れ子は平らにする
          }
        } else if (/^H[1-6]$/.test(c.tagName)) pushBlock('h', c);
        else if (c.tagName === 'LI') pushBlock('li', c);
        else if (c.tagName === 'BR') blocks.push({ type: 'p', runs: [] });
        else pushBlock('p', c);
      }
    };
    visit(root);
    return Logic.normalizeBlocks(blocks);
```

# l_timer

講義用タイマー。講義(既定 50 分)と休憩(10 分 / 60 分)を繰り返し、予鈴・終了音・超過中の経過音で区切りを知らせる。講義中は演習タイマーを重ねて動かせ、右側のエディタに講義メモを書ける。`index.html` と `audio/` だけで動く。

元は単体アプリ <https://github.com/ytx/l_timer>。機能を引き継ぎ、simplePages の規約(1 ファイル、共通ツールバー、設定の保存形式)に合わせて作り直した。

## 機能

- 講義開始 / 休憩開始(2 種類) / 停止。講義は 0 で終了音を鳴らし `+MM:SS` で超過を続け、超過中は一定間隔で経過音。休憩は 0 で終了音、1 秒後に自動で講義開始
- 予鈴: 講義・休憩・演習すべてで終了 N 分前(既定 3 分)
- 終了時刻の調整 `-10 / -1 / +1 / +10`(分)。秒は 00 に丸める。過去にはできない(超過中だけ可)
- 演習タイマー: 講義中(超過中も)に起動できる独立タイマー。タイトル入力(履歴 20 件を候補表示)、分の調整、終了時刻の調整、次の演習の事前設定と自動開始。演習中は講義タイマーを小さく薄く表示
- 休憩開始で演習を一時停止し、講義再開で同じ残りから再開。停止で演習も終了
- エディタ: 太字・箇条書き・見出しの 3 書式。複数文書の保存・切替・削除、下書きの自動保存、貼り付けはプレーンテキスト。本文だけの拡大 75〜400 %。タイマーとの境界をドラッグして幅を変更
- 音 3 種 × 3 バリエーション、音量、ミュート(講義・休憩開始で自動解除)、試聴
- 右上のアイコンで ミュート、エディタ表示、ダーク/ライト、拡大/縮小、フルスクリーン、日英。設定は歯車
- 幅 700px 未満ではエディタをタイマーの下に積む

## 設定項目

| キー | 型/範囲 | 既定 | 説明 |
|---|---|---|---|
| `lecture` | 整数 1〜300 | 50 | 講義時間(分) |
| `break1` / `break2` | 整数 1〜120 | 10 / 60 | 休憩 / 昼休憩(分) |
| `warning` | 整数 1〜10 | 3 | 予鈴(終了の何分前) |
| `tick` | 整数 10〜300 | 60 | 超過中の経過音の間隔(秒) |
| `exercise` / `nextExercise` | 整数 1〜120 | 15 / 15 | 演習 / 次の演習の既定(分) |
| `sound1` / `sound2` / `sound3` | `soundN-1` 〜 `soundN-3` | `-1` | 予鈴音 / 終了音 / 経過音 |
| `volume` | 整数 0〜100 | 50 | 音量 |
| `muted` | 真偽 | false | ミュート |
| `editor` | 真偽 | false | エディタを表示 |
| `editorWidth` | 整数 30〜70 | 50 | タイマー列の幅(%) |
| `editorZoom` | 75 / 100 / 150 / 200 / 300 / 400 | 100 | エディタ本文の拡大率(%) |
| `lang` / `theme` / `zoom` | 共通 | 共通 | 言語 / テーマ / 拡大率(共通設定) |

## URL パラメータ

設定キーと同名のパラメータで指定できる(`?lecture=90&break1=15&warning=5&sound2=sound2-3&editor=1`)。`save=1` を付けると localStorage に保存する。真偽は `1`/`0`、`true`/`false`。範囲外の値は既定に戻る。

タイマーの状態は保存しない。再読込すると停止状態に戻る。文書と下書きは保存する。

## データの保存形式

localStorage キー `simplePages.l_timer`(設定):

```json
{ "version": 1, "settings": { "lang": "ja", "theme": "auto", "zoom": 100, "lecture": 50, "break1": 10, "break2": 60,
  "warning": 3, "tick": 60, "exercise": 15, "nextExercise": 15, "sound1": "sound1-1", "sound2": "sound2-1", "sound3": "sound3-1",
  "volume": 50, "muted": false, "editor": false, "editorWidth": 50, "editorZoom": 100 } }
```

localStorage キー `simplePages.l_timer.data`(文書・下書き・演習タイトル履歴):

```json
{ "version": 1,
  "documents": [ { "id": "doc_1760500000000", "title": "第 3 回", "blocks": [ { "type": "h", "runs": [ { "text": "見出し", "bold": false } ] },
    { "type": "p", "runs": [ { "text": "本文 ", "bold": false }, { "text": "強調", "bold": true } ] }, { "type": "li", "runs": [ { "text": "項目", "bold": false } ] } ],
    "createdAt": "2026-10-15T04:00:00.000Z", "updatedAt": "2026-10-15T04:10:00.000Z" } ],
  "draft": { "documentId": "doc_1760500000000", "blocks": [], "updatedAt": "2026-10-15T04:12:00.000Z" },
  "exerciseTitles": [ "演習 2", "演習 1" ] }
```

文書はブロック(`p` 段落 / `h` 見出し / `li` 箇条書き)と run(`text`, `bold`)の JSON で持ち、HTML は保存しない。

データタブの書き出しは `{ "version": 1, "settings": …, "data": … }`。読み込みは設定を置き換え、文書は追加(id が重なれば改名)、履歴は結合する。旧 l_timer の書き出し JSON(`version: "1.0"`、`settings.timerSettings`、`documents.documents[]`)も読み込め、Quill の HTML は太字・箇条書き・見出しだけ残して取り込む。

## 音声

`audio/sound1-1.wav`(予鈴、mixkit.co `mixkit-correct-answer-tone-2870`)、`sound2-1.wav`(終了、`mixkit-happy-bells-notification-937`)、`sound3-1.wav`(経過、`mixkit-access-allowed-tone-2869`)は Mixkit License。他の 6 本は生成音。読み込めないときはステータスが赤になり、Web Audio の 880 Hz ビープで代替する。

iOS Safari は `<audio>` の音量変更を受け付けないため、音量設定はビープ代替にのみ効く。ブラウザの自動再生制限のため、音は開始ボタンを押した(ユーザー操作があった)あとにだけ鳴る。

## 手動確認

- 講義開始 → `49:59` から減り「終了 HH:MM:SS」。3 分前に予鈴、0 で終了音と赤い `+00:01…`、60 秒ごとに経過音
- 休憩開始 → 緑。3 分前に予鈴、0 で終了音、1 秒後に自動で講義開始
- 講義中に演習 → タイトルを入れて開始。講義タイマーが小さく薄くなる。次の演習を設定しておくと終了時に自動で切り替わる
- 演習中に休憩開始 → 「一時停止中」で止まり、休憩明けに同じ残りから再開。休憩中に停止を押すと演習も消える
- `±` で終了時刻の秒が 00 になる。超過中に `+1` で通常カウントに戻る
- エディタで太字・箇条書き・見出し。リロードで下書きが戻る。保存・切替・削除。貼り付けがプレーンテキスト。`−`/`+` で本文だけ拡縮
- リサイザのドラッグで幅が変わりタイマー文字が追従。ダブルクリックで 50 %
- 旧 l_timer の書き出し JSON をデータタブから取り込むと設定と文書が入る
- 幅 700px 未満でエディタが下に積まれる。ダーク/ライト、拡縮、日英で崩れない
- `audio/` を一時的にリネームするとステータスが赤、ビープで鳴る
