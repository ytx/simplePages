# k_timer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `k_timer/`, a kitchen-timer page with an analog clock, presets, ± adjustments, and a looping end sound, following the simplePages conventions.

**Architecture:** One `k_timer/index.html` copied from `_template/`. `Logic` holds a pure timer state machine (`idle / running / paused / alarm`) driven by `(state, now)` and pure formatters; `App` renders it every 250 ms, drives an `<audio loop>` element plus a Web Audio beep fallback, and wires the settings tabs. Sound files live in `k_timer/audio/` (a documented relaxation of the single-file rule).

**Tech Stack:** Vanilla HTML/CSS/JS, SVG clock, `<audio>`, Web Audio API, `node --test` (Node 20+).

**Spec:** `docs/superpowers/specs/2026-10-14-k_timer-design.md`. Shared conventions: `docs/superpowers/specs/2026-10-12-simplepages-conventions-design.md`, `docs/superpowers/specs/2026-10-13-toolbar-and-settings-modal-design.md`.

## Global Constraints

- One page = `k_timer/index.html`. No external `<link>`, `<script src>`, CDN or web fonts. Only same-directory media (`audio/*.wav`) may be referenced, and only from the constant map `Logic.SOUND_FILES`; never put a setting or URL string into `src`.
- Exactly two globals: `Logic` (in `<script id="app-logic">`, no DOM) and `App` (in `<script id="app-ui">`).
- External strings go through `textContent`. No `innerHTML`.
- Settings: localStorage `simplePages.k_timer` as `{ version: 1, settings }`. Priority URL query > localStorage > default. URL saved only with `?save=1`.
- All setting keys are display-only (`DISPLAY_ONLY_KEYS` holds every key). `refresh()` is an empty no-op. No fetch anywhere.
- Timer state is never persisted. Reload → `idle` with `preset1`.
- Touch targets: `.tbtn` has `min-height: calc(48px * var(--zoom))`, `min-width: calc(56px * var(--zoom))`.
- Below 700 px width the clock column is hidden (`display: none`), no stacking.
- Status bar shows the **date only** (no clock, no "最終更新"). Dot: green normal, red when audio failed.
- `MAX_MS = 180 * 60000`. Adjust steps: `-600000, -60000, -30000, 30000, 60000, 600000`.
- Tests: `node --test k_timer/test/*.test.mjs` (glob form; never a directory). No network.
- Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- i18n: every `data-i18n` / `data-i18n-label` / `Logic.t(settings.lang, '…')` key exists in both `ja` and `en`.

## Review Focus

Behaviours the spec implies but that are easy to miss. Each has a test in the owning task.

1. **Adjusting past the 3-hour cap while running** must clamp `endAt` to `now + MAX_MS` instead of overflowing (Task 3).
2. **`00` while running when `endAt` is already on `:00`** must leave the state unchanged, not jump a minute (Task 3).
3. **Start with 0 remaining** (idle after `-10` from 5:00) must stay idle; nothing to count (Task 3).
4. **`formatRemaining` at 59 999 ms shows `1:00`**, not `0:59` — ceiling keeps the display from skipping the first second (Task 4).
5. **Bool settings from odd URL values** (`flash=yes`) fall back to the default instead of becoming truthy strings (Task 1).
6. **Tapping a button to silence the alarm must not also activate that button** (pointerdown stops the alarm, then click would start a new run). App-level: the click within 700 ms after an alarm stop is swallowed (Task 6, manual check listed).

Insert after `SOUND_FILES`:

```js
  // ---- タイマー状態機械。すべて純粋関数で、新しいオブジェクトを返す ----
  const clampMs = (ms) => Math.min(MAX_MS, Math.max(0, ms));

  function initialState(presetMinutes) {
    const ms = clampMs(presetMinutes * 60000);
    return { phase: 'idle', startMs: ms, remainingMs: ms, endAt: null };
  }

  function toIdle(s) {
    return { phase: 'idle', startMs: s.startMs, remainingMs: s.startMs, endAt: null };
  }

  function toAlarm(s, now) {
    return { ...s, phase: 'alarm', endAt: now };
  }

  // スタート/ストップのトグル。alarm 中は音を止めて idle に戻す。
  function start(s, now) {
    switch (s.phase) {
      case 'idle':
      case 'paused':
        if (s.remainingMs <= 0) return s;
        return { ...s, phase: 'running', endAt: now + s.remainingMs };
      case 'running':
        return { ...s, phase: 'paused', remainingMs: Math.max(0, s.endAt - now), endAt: null };
      default:
        return toIdle(s);
    }
  }

  function reset(s) { return toIdle(s); }

  function preset(s, minutes) { return initialState(minutes); }

  // 停止中は残りと開始値を動かす。動作中は終了時刻だけ動かす(開始値はそのまま)。
  function adjust(s, deltaMs, now) {
    if (s.phase === 'alarm') return s;
    if (s.phase === 'running') {
      const endAt = Math.min(s.endAt + deltaMs, now + MAX_MS);
      return endAt - now <= 0 ? toAlarm(s, now) : { ...s, endAt };
    }
    const ms = clampMs(s.remainingMs + deltaMs);
    return { ...s, remainingMs: ms, startMs: ms };
  }

  // 「00」: 停止中は残りの秒を切り捨て。動作中は終了時刻の秒を 00 に切り下げ。
  function zero(s, now) {
    if (s.phase === 'alarm') return s;
    if (s.phase === 'running') {
      const d = new Date(s.endAt);
      d.setSeconds(0, 0);
      const endAt = d.getTime();
      if (endAt === s.endAt) return s;
      return endAt - now <= 0 ? toAlarm(s, now) : { ...s, endAt };
    }
    const ms = Math.floor(s.remainingMs / 60000) * 60000;
    if (ms === s.remainingMs && ms === s.startMs) return s;
    return { ...s, remainingMs: ms, startMs: ms };
  }

  function tick(s, now) {
    if (s.phase === 'running' && s.endAt - now <= 0) return { ...s, phase: 'alarm' };
    return s;
  }

  function remainingFor(s, now) {
    return s.phase === 'running' || s.phase === 'alarm' ? s.endAt - now : s.remainingMs;
  }
```

Note `tick` keeps the original `endAt` (so the overrun counts from the scheduled end), while `adjust`/`zero` that cross zero use `toAlarm(s, now)` (overrun counts from the moment of the tap). Add to the Logic return: `initialState, start, reset, preset, adjust, zero, tick, remainingFor`.

  const pad2 = (n) => String(n).padStart(2, '0');

  // 残り時間: 正は切り上げ(1 秒残っている間は 0:01)、超過は切り捨てで '-m:ss'。
  function formatRemaining(ms) {
    const neg = ms < 0;
    const sec = neg ? Math.floor(-ms / 1000) : Math.ceil(ms / 1000);
    return `${neg ? '-' : ''}${Math.floor(sec / 60)}:${pad2(sec % 60)}`;
  }

  function sameLocalDay(a, b) {
    return a.getFullYear() === b.getFullYear() && a.getMonth() === b.getMonth() && a.getDate() === b.getDate();
  }

  function formatEndAt(endAt, now, lang) {
    const e = new Date(endAt);
    const time = `${pad2(e.getHours())}:${pad2(e.getMinutes())}`;
    return t(lang, sameLocalDay(e, new Date(now)) ? 'end_at' : 'end_at_tomorrow', { time });
  }

```js
  // ---- 終了音 ----
  const SWALLOW_CLICK_MS = 700;
  let audioBroken = false;   // <audio> が読めない → Web Audio のビープで代替
  let audioCtx = null;
  let beepTimer = null;
  let alarmStoppedAt = 0;
  let previewAudio = null;

  function alarmAudio() { return $('#alarm-audio'); }

  // 設定の音キーを SOUND_FILES の既知キーに丸める。src には必ずこの表の値を入れる。
  function soundKey() {
    return Logic.SOUND_FILES[settings.sound] ? settings.sound : 'sound2-1';
  }

  function loadAlarmSound() {
    const a = alarmAudio();
    const key = soundKey();
    if (a.dataset.sound === key) return;
    a.dataset.sound = key;
    audioBroken = false;
    setStatus('ok', '');
    a.src = Logic.SOUND_FILES[key];
    a.load();
  }

  function markAudioBroken() {
    if (audioBroken) return;
    audioBroken = true;
    setStatus('error', () => Logic.t(settings.lang, 'error_audio'));
    if (timer && timer.phase === 'alarm') startBeep();
  }

  // ユーザー操作(スタート押下)の中で一度だけ無音再生し、alarm 時の play() が自動再生制限で拒否されないようにする
  function unlockAudio() {
    const a = alarmAudio();
    if (!audioCtx && window.AudioContext) {
      try { audioCtx = new AudioContext(); } catch { audioCtx = null; }
    }
    if (audioCtx && audioCtx.state === 'suspended') audioCtx.resume().catch(() => {});
    if (a.dataset.unlocked === '1' || audioBroken) return;
    a.muted = true;
    a.play().then(() => {
      a.dataset.unlocked = '1';
      a.muted = false;
      if (timer && timer.phase === 'alarm') return; // すでに鳴り始めていたら止めない
      a.pause();
      a.currentTime = 0;
    }).catch(() => { a.muted = false; });
  }

  function startBeep() {
    if (beepTimer || !audioCtx) return;
    const beep = () => {
      const osc = audioCtx.createOscillator();
      const gain = audioCtx.createGain();
      osc.type = 'square';
      osc.frequency.value = 880;
      gain.gain.value = 0.3 * (settings.volume / 100);
      osc.connect(gain).connect(audioCtx.destination);
      osc.start();
      osc.stop(audioCtx.currentTime + 0.2);
    };
    beep();
    beepTimer = setInterval(beep, 600);
  }

  function stopBeep() {
    clearInterval(beepTimer);
    beepTimer = null;
  }

  function onAlarmStart() {
    document.documentElement.classList.toggle('alarm', !!settings.flash);
    stopPreview();
    if (audioBroken) { startBeep(); return; }
    const a = alarmAudio();
    a.volume = settings.volume / 100;
    a.currentTime = 0;
    a.play().catch((e) => {
      if (e && e.name === 'NotAllowedError') return; // 自動再生拒否: 画面点滅だけ
      markAudioBroken();
    });
  }

  function onAlarmStop() {
    document.documentElement.classList.remove('alarm');
    const a = alarmAudio();
    a.pause();
    a.currentTime = 0;
    stopBeep();
  }

  // 鳴っている間はどこを触っても止まる。止めた直後の click は飲み込み、押したボタンを誤って作動させない。
  function onAnyInput() {
    if (!timer || timer.phase !== 'alarm') return;
    alarmStoppedAt = Date.now();
    setState(Logic.start(timer, alarmStoppedAt), alarmStoppedAt);
  }

  function swallowClickAfterStop(ev) {
    if (alarmStoppedAt && Date.now() - alarmStoppedAt < SWALLOW_CLICK_MS) {
      ev.stopPropagation();
      ev.preventDefault();
    }
    alarmStoppedAt = 0;
  }

  // 試聴(設定 → タイマー)。1 回だけ再生。alarm 中は無効。
  function togglePreview() {
    if (previewAudio) { stopPreview(); return; }
    if (timer && timer.phase === 'alarm') return;
    previewAudio = new Audio();
    previewAudio.src = Logic.SOUND_FILES[soundKey()];
    previewAudio.volume = settings.volume / 100;
    previewAudio.addEventListener('ended', stopPreview);
    previewAudio.addEventListener('error', () => { markAudioBroken(); stopPreview(); });
    previewAudio.play().catch(() => stopPreview());
    $('#btn-preview').textContent = Logic.t(settings.lang, 'preview_stop');
  }

  function stopPreview() {
    if (previewAudio) { previewAudio.pause(); previewAudio = null; }
    $('#btn-preview').textContent = Logic.t(settings.lang, 'preview');
  }

  function bindAudio() {
    alarmAudio().addEventListener('error', markAudioBroken);
    loadAlarmSound();
    document.addEventListener('pointerdown', onAnyInput, true);
    document.addEventListener('keydown', onAnyInput, true);
    document.addEventListener('click', swallowClickAfterStop, true);
    $('#btn-start').addEventListener('click', unlockAudio, true); // 状態変更(bubble)より先に capture で
    $('#btn-preview').addEventListener('click', togglePreview);
    $('#settings').addEventListener('close', stopPreview);
  }
```
