# time4u

面会の候補日時を相手に送る文面にまとめるスマートフォン向けのツール。週ごとの面会可能帯から空き枠を出し、提示文面の作成、仮押さえ、確定までを記録します。`index.html` 1 ファイルで動き、データはブラウザの localStorage にだけ保存されます。書体は Zen Kurenaido(SIL Open Font License 1.1)を `fonts/zen-kurenaido/` に同梱しています。

## 機能

下部のタブは 4 つ。

- 相手: 面会相手の一覧(確定済み / 調整中 / 過去 / その他)。名前・よみで検索。ここから提示、回答の反映、リマインドに進む。確定済みの行をタップすると、1 行テキスト(名前 日付 時刻)のコピー、リマインド文面、別の予定の調整、取り消し、名前・よみの編集を選べる。見出し右のコピーボタンで確定済み全件を 1 行ずつまとめてコピーできる
- 週: 週ごとに面会可能帯(曜日・時間)と予定(ランチや別件)を置く。右下の「＋」で、可能帯または予定を時刻と曜日(複数選択可)を指定してまとめて追加できる。日ビューで 1 日を詳しく見る(面会の登録は日ビューから)。過去 8 週のうち帯のある週から今週へ帯をコピーできる(追加 / 置き換え)。タイトルをタップすると今週へ戻る
- 月: 月全体の概観。日を選ぶとその週の週タブへ
- 設定: 表示(敬称・週の始まり・表示時間帯)/ 時間 / 文面 / データ / About。言語・テーマ・拡大率は右上のツールバーで切り替える(このページにはフルスクリーンボタンはない)

ツールバー左端の「?」で使い方のモーダルを開く(初回起動時は自動で開く。閉じると localStorage `simplePages.time4u.helpSeen` を立て、全消去で消える)。

提示から確定までの流れ。

1. 提示: 相手を選び、期間・曜日・時間帯・スロット長の条件で空き枠を出す(期間の初期値は面会可能帯が入っている最初の日から最後の日まで。帯がなければ設定の `rangeStartDays` / `rangeDays`。日付は ‹ › で 1 日ずつ、曜日・時間帯は全選択あり。条件を変えるたびに空き枠の件数がその場で表示される)。候補を選ぶ(「おまかせ」で日付と時間帯が散るように自動選択)と、メールや LINE に貼る文面ができる。回答期限を添える(‹ › で 1 日ずつ調整)
2. 仮押さえ: 提示を保存すると、その枠は回答まで空き枠から除外される。期限が過ぎても自動では解放しない
3. 回答: 相手の返事を反映する。1 枠を確定すると面会として記録し、同じ提示の残りの枠を解放する。決まらなければ「再提示」で別の枠を探す(すでに提示した日程は候補から外れ、新しい提示を保存した時点で元の提示を取り消す)、または取り消し
4. リマインド: 確定した面会に送る文面を作る

文面は設定の 3 つのテンプレート(提示ヘッダ / 提示フッタ / リマインド)から作る。ビジネス調とくだけた調の文例をボタンで読み込める。


## 設定項目

| セクション | キー | 型 | 既定 | 説明 |
|---|---|---|---|---|
| 一般 | `lang` | `'ja' \| 'en'` | 言語検出 | 共通 |
| 一般 | `honorific` | 文字列(0〜10 文字) | ja: `さん`、en: 空 | 名前の後ろに付ける敬称。空も可 |
| 表示 | `theme` | `'auto' \| 'light' \| 'dark'` | `auto`(OS) | 共通 |
| 表示 | `zoom` | 50〜200 | 100 | 共通 |
| 表示 | `weekStart` | 0 \| 1 | 1(月曜) | 週・月の始まりの曜日 |
| 表示 | `dayStart` | 0〜23 | 8 | 週・日ビューの軸の開始時 |
| 表示 | `dayEnd` | 1〜24 | 21 | 同終了時。`dayStart` 以下なら既定に戻す |
| 時間 | `slots` | 文字列(カンマ区切りの整数、各 10〜480) | `'60,90,120'` | 選べるスロット長(分)。1〜6 個。`parseSlotList` で配列にして使う。保存時に昇順・重複除去に正規化 |
| 時間 | `defaultSlot` | 整数 | 90 | `slots` に含まれない値なら先頭に補正 |
| 時間 | `interval` | 0〜120 | 10 | 面会・仮押さえの前後に空ける時間(分)。提示候補同士の間には挟まない |
| 時間 | `deadlineDays` | 0〜30 | 3 | 回答期限の既定(日後) |
| 時間 | `pickCount` | 1〜10 | 3 | 「おまかせ」の件数 |
| 時間 | `rangeStartDays` | 0〜60 | 1 | 条件の期間の下限(本日から何日後)。面会可能帯があればその最初の日が開始になる |
| 時間 | `rangeDays` | 1〜90 | 21 | 面会可能帯がないときの既定期間の長さ(日) |
| 時間 | `pmStart` | 1〜23 | 12 | 「午後」の開始時 |
| 時間 | `eveStart` | 2〜24 | 17 | 「夜」の開始時。`pmStart` 以下なら既定に戻す |
| 文面 | `tplHeader` | 文字列 | フレンドリー文例 | 提示ヘッダ |
| 文面 | `tplFooter` | 文字列 | フレンドリー文例 | 提示フッタ。`{期限}` を差し込む |
| 文面 | `tplReminder` | 文字列 | フレンドリー文例 | リマインド。`{日時}` を差し込む |

## URL パラメータ

設定キーと同名のパラメータで指定できる(`?theme=dark&zoom=120&lang=en`)。共通で使えるのは `theme` `zoom` `lang`。

- `tab`: 開くタブ。`clients`(既定) / `week` / `month` / `settings`
- `save=1`: 指定した設定値を localStorage に保存する(付けなければ保存しない)

優先順位は URL クエリ > localStorage > 既定値。範囲外の値は無視される。

## データ形式

localStorage に次の 2 つのキーで保存します。

- `simplePages.time4u` — `{ version, settings }`。上の設定項目。
- `simplePages.time4u.data` — `{ version, clients, bands, blocks, proposals }`。相手、面会可能帯、予定、提示(仮押さえ・確定)。

書き出しは設定とデータを 1 つにまとめた JSON で、ファイル名は `time4u-YYYYMMDD.json`。データタブは移行の経路ごとに 3 段に分かれている: ファイル経由(「ファイルへ保存」「ファイルから読み込む」)、クリップボード経由(「テキストをコピー」「クリップボードから読み込む」。メモやメッセージに貼って別の端末へ運ぶ)、直接編集(テキスト欄の JSON を書き換えて「テキストから読み込む」)。「すべて消去」はいちばん下。

```json
{
  "version": 1,
  "settings": { "lang": "ja", "slots": "60,90,120" },
  "data": { "version": 1, "clients": [], "bands": [], "blocks": [], "proposals": [] }
}
```

読み込みは `settings`、`data`、または両方を受け付け、含まれている側を**置き換える**(統合はしない)。実行前に確認を出す。含まれていない側は変更しない。「すべて消去」は 2 つのキーを両方消して既定値に戻す。

## ホーム画面への追加(PWA)

`manifest.webmanifest` と `icons/` を同梱しているので、Android Chrome の「インストール」や iOS Safari の「ホーム画面に追加」で全画面のアプリとして開ける(`display: standalone`)。Service Worker は置いていないので、起動には通信が要り、更新は普通のページと同じく次回起動時にサーバーから読み直す(開いたままなら閉じて開き直す)。iOS ではホーム画面から開いたアプリとブラウザで localStorage が別になるため、データはエクスポート/インポートで移す。アイコンは `icons/icon-192.png` / `icon-512.png`(maskable 兼用)と `icons/apple-touch-icon.png`(180px)。
